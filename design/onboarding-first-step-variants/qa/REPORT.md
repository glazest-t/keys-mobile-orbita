## Визуальная проверка

Источник и реализация просмотрены вместе в comparison.png, затем после исправлений в comparison-final.png. Исходник уменьшен пропорционально до ширины 393 px; iPhone вырезан из реального снимка до 393×852 без изменения масштаба. У исходника нет системной строки и home indicator; в прототипе эти области сохранены по контракту runtime и исключены из претензий к дизайну. Контрольный Pixel — pixel-final.jpg.

Первый проход: P2 — пустая высота вторичного действия под CTA, иллюстрация и заголовок меньше выбранной композиции. Исправлено: пустой ряд удалён только на первом шаге, hero увеличен до 440 px, заголовок 32/40, горизонтальные отступы CTA 24 px. Сокращён нижний технический отступ стека, чтобы увеличенная иллюстрация не создавала лишний запас прокрутки.

Повторный проход: композиция, единая панель, три подписи, цвета и читаемость соответствуют выбранной идее. Контент и главное действие помещаются на iPhone и Pixel. P0/P1/P2 не осталось. P3: геометрия иконок отличается от сгенерированных — намеренно использован UI kit приложения; реальные Onest/Unbounded дают небольшое отличие ширины надписей. Иллюстрация повторно сгенерирована без UI, поэтому отдельные детали спальни немного отличаются.

## Поведение

В IAB проверены первый шаг → «Дальше» → второй, «Назад» → первый, «Пропустить» → третий, возврат через первый индикатор. При смене шага используются прежние crossfade/slide, панель и действия — прежний stagger D-011; memo сохраняет DOM. Reduced motion отключается общим CSS проекта; системную настройку в браузере отдельно не переключали. Редактирования регистрации, подтверждения статуса, ключа и Wi-Fi не было.

Production build прошёл; protected runtime check — 28 файлов. Новые unit-тесты не добавлялись для визуального изменения без новой бизнес-логики. Реальные подключения Wi-Fi и двери не добавлялись.
