# Ключи · Мягкий контур

Источник: https://keys-soft-contour-icon-atlas.bapiwork2020.chatgpt.site/ .
Пользователь утвердил замену 20.11.2026, с приоритетом **v2**.

- 254 позиции из атласа. Все 15 вариантов v2 извлечены как SVG с исходными контурами; Google Maps содержит необходимые встроенные определения градиентов и масок.
- Остальные позиции извлечены из встроенных растровых листов без перерисовки и масштабирования: контуры 96 × 96 px, цветные удобства 88 × 88 px. Они предназначены для размеров интерфейса 16–44 px.
- Для heart и points/points-earned использованы специальные изображения, которыми атлас переопределяет основные листы.
- Единственное дополнение — microphone.svg из предыдущего набора: в атласе микрофон отсутствует.
- Файлы в app/public/brand/assets/icons-contour идентичны мастер-копиям. manifest.json содержит источник, его SHA-256, версии и хеши файлов; app/src/iconAtlas.json — имена, алиасы и признак цветного изображения.
- Контурные иконки рисуются CSS-масками с цветом темы или родителя. Цветные удобства, логотипы карт и радиокнопка v2 отображаются без маски. Исходный набор остаётся доступен переключателем «Старые иконки».
- Устройства, статусная строка, клавиатура и остальные protected runtime assets не изменены.

Повторный импорт: сохранить HTML указанного источника, затем выполнить `python3 scripts/import-icon-atlas.py /path/to/atlas.html` в отдельной Python-среде с Pillow. Скрипт читает данные и извлекает ассеты, не исполняет скрипты сайта. Pillow не является зависимостью приложения или CI.

Проверка: `npm --prefix app run check:icons`. Каталог приложения: `?catalogue=kit&icons=new`.
