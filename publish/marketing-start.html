Комплект содержит логотипы, шрифты, цвета, UI, актуальные иллюстрации и готовые композиции. Сохраняйте фирменный стиль, меняя содержание под свою задачу.

Для сайта или лендинга

  1. Начните с цветов и шрифтов в CSS или токенов JSON. Основной акцент — #2F5BFF, заголовки — Unbounded 500, основной текст — Onest 400/500.
  2. Возьмите горизонтальный логотип SVG, Onest и Unbounded. Лицензии шрифтов входят в папку fonts.
  3. Выберите широкий баннер в категориях «Сайт и ссылки» и «Новые промо». Примеры: персональный подбор, короткая поездка, места рядом.
  4. Для адаптивной страницы используйте отдельную иллюстрацию PNG, а заголовок, пояснение и кнопку соберите в HTML. Изображение со встроенным текстом подходит для превью, но плохо адаптируется к узкому экрану.
  5. Сохраняйте свободное место вокруг знака, короткий заголовок и один основной призыв. Размеры текста и расположение иллюстрации подстраивайте под экран.

Пример подключения после копирования папки fonts рядом с вашим CSS:

@font-face {
  font-family: Onest;
  src: url("./fonts/Onest-Variable.ttf") format("truetype");
  font-weight: 100 900;
  font-display: swap;
}
@font-face {
  font-family: Unbounded;
  src: url("./fonts/Unbounded-Variable.ttf") format("truetype");
  font-weight: 200 900;
  font-display: swap;
}
body { font-family: Onest, sans-serif; color: #101320; }
h1, h2 { font-family: Unbounded, sans-serif; font-weight: 500; }
button { background: #2F5BFF; color: white; border-radius: 16px; }

Для соцсетей и рекламы

  1. В каталоге выберите «Соцсети», «Рекламные баннеры» или «Новые промо». Доступны квадраты 1080 × 1080, вертикальные публикации 1080 × 1350, stories 1080 × 1920 и широкие форматы.
  2. Для изменения заголовка скачайте SVG с текстом из editable и установите шрифты. Для передачи без шрифтов используйте SVG в кривых из outlined. Иллюстрации внутри SVG могут оставаться растровыми.
  3. PNG готов к размещению. Перед выпуском проверьте текст предложения, сроки, кадрирование и расположение интерфейса площадки поверх stories.
  4. Новые темы: короткая поездка, избранное, места рядом, завтрак.

Для дизайнера и разработчика

  • Текущая графика приложения — исходники и готовые композиции с указанием места использования. Здесь находятся актуальные «Горячие скидки», Friendly Rate, онбординг и 32 иллюстрации предпочтений.
  • Основа бренда — логотипы, иконки, изображения предпочтений и промо.
  • Орбита из брендбука — с подписью, без подписи и на прозрачном фоне.
  • Реестр макетов содержит размеры, тексты и пути SVG/PNG. Реестр исходников приложения содержит источники использования и контрольные суммы.
  • Промпты новых иллюстраций помогают продолжать визуальную серию. Используйте мягкие перламутровые формы, тонкую кобальтовую орбиту и спокойный фон.
  • Статические UI-файлы подходят для макетов и промо. Поведение приложения, анимации и интерактивные состояния берите из исходного кода проекта.

Фотографии контента приложения сохранены с источниками; это отдельный раздел каталога. Новые рекламные тексты и баннеры отмечены как предложения для кампаний.
