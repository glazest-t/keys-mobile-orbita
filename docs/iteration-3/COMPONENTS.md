# Базовые компоненты

Открыть `http://127.0.0.1:5173/#kit`. Это те же компоненты, которые используются в приложении.

| Компонент | Входные данные и событие | Состояния |
|---|---|---|
| Button | children, variant, busy, busyLabel, success, disabled, onClick, form/type | primary, secondary, ghost, danger; focus, pressed, loading, disabled |
| Field | label, prefix, hint, error, value, onChange, стандартные параметры ввода | empty, filled, focus, invalid, disabled |
| Icon / Mark | имя исходной SVG, размер; знак 28 px | Исходные ассеты brand-kit |
| IconButton | name, label, onClick | Фокус, доступная подпись, область 44 px |
| Row | icon, title, subtitle, onClick | Строка действия, перенос длинных подписей |
| Empty | icon, title, children, action | Пустое состояние с дальнейшим действием |
| BottomSheet | open, onOpenChange, title, snap, children | Телефонный слой, Escape, закрытие, удержание фокуса |
| Навигация | route, переход | Активная вкладка, история, возврат |
| Обратная связь | текст и состояние | Toast, banner, badges, skeleton |

Field использует KeyboardInput мобильного runtime. При навигации клавиатура скрывается, фиксированная кнопка учитывает её высоту; активное поле прокручивается к центру. Синий контур телефона отсутствует и при фокусе. Ошибка связана с полем через aria-describedby, есть aria-invalid. Переключатель имеет role=switch и aria-checked. Загрузка блокирует повторное действие.

Иллюстрации o1–o3 и a1 извлечены из исходного HTML. Маршруты: o1–o3 → #welcome; a1 → #phone; код → #code; имя → #name; профиль → #profile; гости → #travelers/#traveler/#edit. Экран поиска f1 пока реализован частично.

Календарь, состав гостей, карточки отеля и тарифа, цена и оплата добавлены в первом пути итерации 4 (см. ниже). Следующие группы: ключ, услуги и чат (5); подбор (6); полная лояльность и Friendly Rate (7). Это очередь, а не уже готовые компоненты.

## Микровзаимодействия — дополнение 21.10.2026

Источник: UI Kit F4/B1/S2/N2/N4/N5, каталог 09. Внешний вид берём из «Все экраны» (D-009), онбординг — github-onboarding (D-011). Новые экраны используют эти общие компоненты и согласованные правила продукта (D-012).

| Компонент | Реализованное поведение |
|---|---|
| Button, IconButton, Row, текстовые действия | Нажатие scale .97 за 120 мс; отпускание 240 мс arrive (.2,.8,.2,1). Disabled/busy не реагирует; drag не превращается в click |
| Нижнее меню | Crossfade содержимого 200 мс ease без сдвига; уходящий экран inert и скрыт от accessibility; повторный тап прокручивает к началу без нового history entry |
| Активная вкладка | Сохраняется подложка без точки; перемещение 240 мс ios-push, как у сегмента UI Kit |
| Switch | Бегунок и цвет 300 мс click (.34,1.56,.64,1), role=switch, aria-checked, disabled |
| Toast | Появление/уход 300 мс arrive, смещение 16 px; показ 2,6 с |
| Reduced motion | Нажатия без масштабирования, тумблер и подложка без перемещения во времени; вкладки через opacity 200 мс; тост opacity 200 мс |

Нижнее меню скрывается при открытой шторке и клавиатуре. После закрытия шторки фокус возвращается без прокрутки внешнего устройства. Служебная рамка и статусная строка не анимируются.

Границы этого дополнения: переходы вложенных экранов 460/380 мс, точные тайминги шторок 460/340 мс, сердце и цифровой ключ остаются отдельными задачами. Шторка сейчас использует защищённый компонент runtime с пружиной; он не изменён и не объявляется совпадающим с точными длительностями UI Kit. Тактильная отдача в браузере не имитируется.
