# Итерация 3 — вход, профиль и базовые компоненты

> Здесь зафиксирован результат итерации 3. Текущий поиск, бронь и отмена описаны в [итерации 4](../iteration-4/README.md).

Запущенный прототип: http://127.0.0.1:5173/. Код входа: **123456**. SMS не отправляются. Используйте вымышленные данные.

## Что работает

- Три шага знакомства из o1–o3, переход в приложение и вход.
- Телефон → код → имя для нового пользователя; повторный вход без повторного имени.
- Неверный и истёкший код, повтор через 30 секунд; срок кода — 5 минут.
- Профиль, добавление и редактирование путешественников, удаление дополнительного гостя, проверка полей, защита несохранённых изменений.
- Сохранение профилей и выбранного гостя на этом устройстве; выход и сброс демонстрации.
- Четыре вкладки, шторки и базовый живой UI kit на маршруте `#kit`.

Дизайн основан на «Все экраны». Иллюстрации и фото перенесены из оригинала, Onest и Unbounded загружаются локально. Поле телефона без синей рамки и свечения. При открытии клавиатуры иллюстрация временно скрывается, чтобы поле и подтверждение оставались доступны.

Обновление D-011: анимации перенесены из github-onboarding. Заставка «ключ → орбита», плавная смена шагов, последовательное появление элементов, кликабельные полоски прогресса и завершение с переходом в поиск или вход. Повтор — кнопка «Онбординг» рядом с телефоном. Системный режим уменьшенного движения отключает анимации и ожидание заставки.

## Границы этапа

Поиск пока содержит начальный экран и выбор города. Выдача, календарь, номер, тариф, бронь и оплата — итерация 4. Поездки и чаты пока пустые; ключ и услуги — итерация 5. Полная библиотека предметных компонентов пополняется по мере реализации. Онбординг переключается кнопками. Реальные интеграции отсутствуют.

## Устройство проекта

`app/` — React + TypeScript + Vite. Общие компоненты в `src/ui.tsx`, сценарии в `src/Prototype.tsx`, состояние в `src/state.ts`. Защищённый мобильный runtime описан в `app/AGENTS.md`. Копия брендовых ресурсов в `app/public/brand` позволяет запускать приложение самостоятельно.

Для повторного запуска из `app/`: `npm ci`, затем `npm run dev -- --host 127.0.0.1`. Для сборки: `npm run build`. Для тестов из корня проекта с Node 24: `node --test app/tests/auth.test.mjs tests/*.test.mjs`.

Проверки: 39 тестов логики, TypeScript и production build, неизменность 28 файлов runtime, валидаторы продукта и бренда. В браузере проверены новый и повторный вход, ошибка и истечение кода, путешественники, шторки, сохранение и клавиатура. Детали визуальной сверки: [design-qa](../../app/design-qa.md).

26.10.2026, D-069: SMS-код вводится в шесть отдельных KeyboardInput (SmsCodeField.tsx), в существующем стиле полей с нейтральным фокусом. Ввод цифры переводит фокус вперёд; Backspace очищает текущую ячейку, в пустой — предыдущую; стрелки перемещают фокус. Вставка/автозаполнение шести цифр заполняет весь код. Пустая ячейка в середине не сдвигает остальные цифры; подтверждение доступно только для шести цифр. Доступные названия «Цифра N из 6», общий текст ошибки. Правила проверки кода и повторной отправки сохранены. Проверены внешний вид, массовый ввод, удаление и доступность кнопки в браузере; вход пользователя при проверке не выполнялся.


26.10.2026, D-070: после ввода шестой цифры SMS-код проверяется автоматически через verifyCode. При успехе ячейки получают фирменное зелёное состояние, появляется «Код верный», клавиатура скрывается; через общий interactionMotion.successHoldMs (1500 мс) открывается имя нового гостя или сохранённый маршрут существующего. Кнопка подтверждения убрана. Неверный/истёкший код оставляет пользователя на вводе с ошибкой. Таймер отменяется при смене кода, запроса, маршрута и размонтировании; до окончания успешного состояния авторизация не записывается. Проверен автоматический переход нового гостя в браузере; сборка/runtime прошли.


26.10.2026, D-071: по просьбе пользователя подтверждение SMS-кода смягчено кривой «Орбита» var(--k-ease-orbit) / cubic-bezier(.65,0,.35,1). Цвет фона, рамки и цифр меняется за общий base 400 мс; сообщение и галочка появляются через opacity и сдвиг 8 px без пружинного увеличения. Формы кода и имени используют тот же общий эффект появления в interactions.css; при reduced motion движение отключено. Тайминг автоперехода 1500 мс сохранён. На шаге имени удалено пояснение «Так к вам будут обращаться в отеле». Экран проверен в браузере; сборка/runtime пройдены.
