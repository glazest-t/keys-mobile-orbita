# Маска телефона · D-038

На экране входа и в UI kit используется общий PhoneField на основе Field / KeyboardInput. Внешний вид поля и нейтральный фокус сохранены. Префикс +7 неподвижен, маска номера — (900) 000-00-00. В состоянии хранятся цифры; запрос кода использует прежнюю нормализацию +79001234567.

Проверены 17 автоматических тестов маски и авторизации: пустой/частичный/полный ввод, вставка с +7 и 8, удаление через разделители, выделение, сохранение позиции курсора, валидация номера и подтверждение телефона. TypeScript/Vite build и контроль 28 защищённых файлов runtime проходят. Защищённый runtime не менялся.

Во встроенном браузере проверены ввод 9001234567 → (900) 123-45-67, Backspace, вставка с 8 и +7, замена выделенных 123 на 987, переход к коду с правильным номером +7 900 123-45-67. Снимок phone-mask.png. Фокус серый, маска и действия читаются при открытой клавиатуре. Отдельный headless-скрипт verify-phone-mask.mjs остановился по таймауту загрузки страницы; браузерная проверка завершена через встроенный браузер.
