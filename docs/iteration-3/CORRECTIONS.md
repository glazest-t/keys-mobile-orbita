# Исправления макетов и реализации

Исходный экспорт остаётся неизменяемым архивом. Поправки применяются к рабочим эталонам брендбука и приложению. Это проверка перенесённых экранов, а не заявление о проверке всех 117 макетов.

| Место | Исправление | Основание |
|---|---|---|
| a1, телефон | Убраны постоянная синяя рамка и свечение. Нейтральный контур, серый фокус, красный контур только при ошибке | Прямое замечание пользователя, D-010 |
| o1–o3, подписи | Ключ только после заселения; FR не суммируется с программой отеля; нет обещаний неподтверждённого начисления | D-005–D-008 |
| Формы, подтверждение | Кнопка сохраняет положение во время нажатия; закрытие клавиатуры не отменяет клик | Проверка в браузере |
| Телефон с клавиатурой | Иллюстрация скрывается на время ввода; активное поле прокручивается в видимую область | Проверка Pixel и iPhone |
| Карточка путешественника | Выбранный ID сохраняется; обновление страницы не подменяет гостя | Проверка сценария |
| Несохранённая форма | Сохранение продолжает выбранный переход; отмена новой карточки возвращает в профиль | Проверка переходов |

В следующих итерациях проверять каждый переносимый макет: лишние контуры, перекрытия, подписи, суммы, доступность действий и соответствие утверждённой логике. Дизайн сохранять, каждое существенное отступление фиксировать.
