## Обновление

GitHub Actions запускается при push в main: зависимости, тесты, проверки, `npm --prefix app run build:pages`, проверка готового `_site` и deployment Pages. Защищённый runtime и Vite-конфигурация не изменяются: префикс GitHub задаёт отдельный build adapter.

Сборка использует явный список публикуемых документов и материалов. Исходные HTML-макеты, извлечённые старые экраны, альтернативные концепции и старые дизайн-превью не копируются. Эти файлы исключены также из main; локальные экземпляры сохранены через `.gitignore`. Список — `publish/archived-visuals.json`. История Git не переписывалась.

Каталог определяется `app/src/catalogue/scenes.json`. Для нового экрана добавьте состояние и проверьте его открытие. Режим `screens.html?verify=1` последовательно открывает рецепты и показывает ошибки подготовки. Автоматическая проверка не заменяет визуальный просмотр и сквозную приёмку.
