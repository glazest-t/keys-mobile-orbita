# Публикация мобильного проекта

Сайт: https://glazest-t.github.io/keys-mobile-orbita/

- `/prototype/` — полный интерактивный прототип и настройки сценариев.
- `/screens.html` — одна страница текущих экранов и состояний. Превью используют ту же сборку и независимые данные.
- `/docs/brand/index.html` — брендбук 2.0 с актуальными примерами и компонентами.
- `/documentation.html` — действующий пакет для разработки.

## Обновление

GitHub Actions запускается при push в main: зависимости, тесты, проверки, `npm --prefix app run build:pages`, проверка готового `_site` и deployment Pages. Защищённый runtime и Vite-конфигурация не изменяются: префикс GitHub задаёт отдельный build adapter.

Сборка использует явный список публикуемых документов и материалов. Исходные HTML-макеты, извлечённые старые экраны, альтернативные концепции и старые дизайн-превью не копируются. Эти файлы исключены также из main; локальные экземпляры сохранены через `.gitignore`. Список — `publish/archived-visuals.json`. История Git не переписывалась.

Каталог определяется `app/src/catalogue/scenes.json`. Для нового экрана добавьте состояние и проверьте его открытие. Режим `screens.html?verify=1` последовательно открывает рецепты и показывает ошибки подготовки. Автоматическая проверка не заменяет визуальный просмотр и сквозную приёмку.

## Границы

Данные демонстрационные, хранятся в браузере. SMS 123456; PIN 1234. Встроенные catalogue-превью не читают и не перезаписывают пользовательские брони. Реальные платежи, ключ, биометрия, SMS и ответы отеля не подключены. Десктоп — после приёмки мобильной версии.

## Материалы для маркетинга · 03.11.2026

Раздел `/marketing/` публикует полный комплект: 124 макета/элемента/страницы, 28 страниц стилистики, 929 исходных файлов приложения, отдельные SVG/PNG, шрифты, токены и руководство по использованию для сайтов, лендингов и соцсетей. Ссылка доступна на главной странице и в общей навигации.

Пакет хранится в GitHub Release `marketing-2026-11-03`; фиксированные URL и SHA-256 — `publish/marketing.json`. Сборщик проверяет хеш ZIP, извлекает его в `_site/marketing/` и добавляет навигацию/инструкцию для сайта. Для локальной проверки можно задать `MARKETING_ARCHIVE` абсолютным путём к этому же ZIP. Содержимое приложения не меняется этим выпуском. Проверка — `python3 scripts/validate_marketing.py`.

## Desktop publication: 03.11.2026

По прямому разрешению пользователя сайт публикует обе версии: `/prototype/`, `/desktop/` и просмотр сценариев `/desktop/review.html`. Исходники desktop/ включены в GitHub. Старые макеты не публикуются. GitHub Actions устанавливает зависимости и собирает обе версии. На Pages у них общий origin и совместимое хранилище; каталог изолирован.
