# Счёт и отзыв после проживания · 23.10.2026

В счёте оставлена одна кнопка пополнения. Мятный баланс — не кнопка, без плюса. Открытие существующей формы пополнения проверено; расчёты депозита не менялись.

Новый сценарий отзыва следует x2 из «Все экраны» и R01–R03 функционального документа: карточка отеля, оценка 1–5, положительные темы и темы улучшений, необязательный текст, фотографии, нижнее действие. Награда из макета не показана: начисления отложены в плане. Подтверждение использует мятную галочку и кнопку «Готово».

178 тестов прошли. Новые проверки: завершённость поездки, отменённая бронь, права владельца/управляющего/читателя, идемпотентность, независимость финансов, сохранение после сериализации, шкала/длина/темы/фотографии, связь с одной бронью. Сборка TypeScript/Vite и контроль 28 защищённых файлов прошли; сохраняется предупреждение о крупных чанках.

Сквозная браузерная проверка `scripts/verify-stay-review.mjs` в отдельном профиле: единственная кнопка пополнения и открытие формы; переход из завершённой поездки; обязательность оценки; темы и текст; отказ для TXT и шести фото; добавление и удаление PNG; отправка, подтверждение, возврат; перезагрузка и просмотр сохранённого отзыва; запрет до выезда. Ошибок страницы нет. Файловое содержимое для проверки создано из изображения тестового отеля. Текущие данные пользователя не изменены.

Снимки: `bill-single-topup.png`, `review-rating.png`, `review-success.png`, `review-saved.png`. Проверены визуально. При автоматизации учтено перекрытие скролл-контейнера фиксированной нижней кнопкой; защищённый runtime не менялся.

Границы: один локальный отзыв на поездку, без редактирования после отправки, серверной публикации, бонусов и чаевых. Вход из уведомлений и оценка первой ночи пока не реализованы. Фото хранятся в уменьшенном JPEG; переполнение хранилища переводит в существующий режим памяти с предупреждением.
