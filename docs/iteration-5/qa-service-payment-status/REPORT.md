# D-065: услуги, статусы оплаты и счёт
26 октября 2026.

Изменения: депозит удалён из UI (компонент пополнения удалён); расчёты исторических депозитных операций сохранены. Счёт доступен из деталей проживания, до заселения вход скрыт и прямой маршрут возвращает к поездкам. Платёж услуг — обычные способы и баллы.

Проверка в браузере:
- Реальная страница завтрака: фиксированная панель со сводкой, зелёным статусом «Оплачено» и «Добавить ещё»; снимок breakfast-paid.png.
- Оплаченная услуга: сводка, зелёный статус, сумма и действия на общей нижней поверхности; service-paid.png.
- Отдельная временная бронь в памяти: неоплаченный завтрак → оплата СБП без депозита → «Оплачено» → «Добавить ещё» → та же дата → отдельная оплата.
- При закрытии повторной оплаты первая услуга остаётся оплаченной, вторая явно ожидает оплаты. В раскрытии показаны обе, со своими статусами.
- Реальная поездка: блока счёта нет; детали → «Счёт проживания» → счёт без депозита. Доступ к документам сохранён по прежней логике.
- Никаких тестовых оплат в пользовательской брони не создавалось; временный стенд удалён.

44 доменных теста прошли: запросы/повтор, оплата/отказ/отмена, каталог, счёт, совместимость старых депозитных операций и групповая оплата завтраков. Новый тест проверяет отдельные платёжные операции повторного заказа и отсутствие влияния его отмены на первый.
Сборка и целостность runtime прошли. Консоль проверена при браузерной проверке.
Ограничения: реальные платежи не подключены. Время раннего/позднего выезда нельзя повторно купить как независимую услугу.

В основном приложении консоль без ошибок. В удалённом временном стенде при HMR был предупреждающий лог повторного createRoot; коду приложения он не относится.
