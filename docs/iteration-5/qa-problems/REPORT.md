# s6: проверка обращения

23.10.2026. Источник: «Все экраны», s6, и U05 функционального DOCX. Форма проверена в мобильном браузере, область приложения 393 × 852 CSS px.

- Категории 2 × 3, высота 76/r18, исходные иконки, выделение #EEF0FF. Поле 96/r16, фото 48/r14, кнопка 52/r14. Использованы FlowStack, KeyboardTextarea и общие реакции.
- Первый осмотр выявил сброшенные отступы footer из-за отсутствующей CSS-переменной и тёмные иконки. Исправлены fallback safe area и цвет родителя. form.png — повторная проверка после исправления.
- Проверены ошибка пустого описания «Другое», ввод текста, смена категории, отправка и «Готово» с возвратом в поездку.
- sent.png — описание и статус. resolved.png — завершение с журналом. Статус меняется в демоинструментах: отправлено → в работе → решено.
- После перезагрузки запись сохранилась (history.png), статус виден в поездке. При автоматическом клике по элементу вне видимости прокрутилась оболочка устройства; перезагрузка сбросила её положение. Защищённый runtime не изменялся.
- 158 тестов прошли. Пять новых проверяют неизменность финансов, идемпотентность, доступ и его отзыв, ограничения до/после проживания, данные/фото и последовательность статусов.
- Сборка TypeScript/Vite и 28 защищённых файлов проходят. Предупреждение о крупных чанках остаётся.

Ограничения: системный выбор файла, преобразование реального фото, Android и переполнение localStorage в браузере в этом проходе не проверялись. Проверена доменная валидация фото. Реальной отправки отелю нет. В текущей поездке оставлено одно решённое тестовое обращение «Свет».
