# Отмена услуг · D-079 · 27.10.2026

## Исправления

- Старый completed у будущего раннего заезда/позднего выезда больше не скрывает отмену. Обработка не переписывает платежи; эффективное состояние определяется по времени проживания. Ранний заезд после фактического заселения остаётся использованным.
- Демоконтроль не позволяет заранее завершить услуги времени.
- Общая serviceCancellationAvailability управляет кнопкой и бизнес-командой. Отмена недоступна для отменённых/отклонённых заказов, использованных услуг, завершённой поездки и некорректного времени. При недоступности есть причина.
- В подтверждении отмены вновь виден предмет действия — название услуги.
- В группе завтраков можно открыть каждый день и отменить его отдельно, включая переход после групповой оплаты. Убрано принудительное открытие оплаты/успеха при обычном просмотре группы.
