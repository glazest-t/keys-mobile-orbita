# Проверка чата ch1/ch2 · 26 октября 2026

Основа: «Все экраны» ch1/ch2, функциональное описание C01–C03, D-028 и общие компоненты/анимации. Объём этого прохода — диалог по существующей брони и его строка в списке.

## Реализовано

- Белые входящие и кобальтовые исходящие сообщения, время, разделитель дат, быстрые вопросы, капсула ввода с кнопкой отправки. В шапке — отель и лейбл ИИ, без даты и номера брони.
- Локальные ответы о заезде/выезде, завтраке, парковке, адресе, Wi-Fi, ключе и услугах. Ответы читают выбранную бронь; тексты не создают заказ и не списывают деньги. Контекстные кнопки открывают существующие экраны.
- Черновики по участнику и брони, история по брони, идемпотентный ответ и совместимость старых сообщений. Владелец и получатель полного управления имеют доступ.
- Ожидание 1200 мс, индикатор набора и общая Orbit-анимация. Закрытие чата отменяет таймер; возвращение продолжает ожидающий ответ. Reduced motion отключает движение.
- Список диалогов показывает последнюю реплику/время, группирует строки в белом блоке и сортируется по последней активности.
