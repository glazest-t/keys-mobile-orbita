# Мобильная версия · приёмка

30.10.2026. [Открыть прототип](http://127.0.0.1:5173/#trips) · [Пакет для разработки](handoff/README.md) · [QA этого прохода](iteration-9/qa-mobile-2026-10-30/REPORT.md).

Десктоп начинается после вашей финальной проверки. Переключатели демонстрации находятся вне телефона; они не являются частью пользовательского интерфейса.

## Проверить по порядку

1. **Вход.** Шесть сценариев: новый гость, приглашённый отельер, зарегистрированный отельер, зарегистрированный гость, PIN, биометрия. СМС `123456`, PIN демосценария `1234`. У каждого одна стартовая заставка; ошибка биометрии предлагает PIN. У обычного гостя нет подтверждения отельера и Friendly Rate.
2. **Поиск.** «Куда» → даты → гости; отдельно редактирование дат/гостей. Фильтры, сортировка, пустая выдача, карта, фото и избранное. Текстовый запрос сразу открывает результаты, объяснения закрыты. Свайп-подбор сохраняет лайк без промежуточного окна.
3. **Бронь.** Отель → номер → данные/дополнительный гость → время/услуги → оплата. Проверить СБП, раздельные кошельки, раскрытие итога. «Следующая оплата: отказ» позволяет проверить ошибку и повтор без двойного списания. На подтверждении видны выбранные услуги.
4. **Все стадии поездки.** Брони нет → до заезда → проживание → день выезда → после выезда. Ключ только во время проживания; день выезда содержит информационный блок. «Оформить выезд в отеле» закрывает ключ, открывает завершённую поездку и оценку.
5. **Услуги.** Ранний/поздний выезд добавляется сразу без оплаты, зелёное «Добавлено», цена с оплатой при заселении/выезде. Добавление/отмена закрывает шторку и даёт хинт. Завтрак на один/все дни: заказ → оплата → «Готово» → поездки; оплаченный заказ можно просмотреть или добавить ещё. Депозита в интерфейсе нет.
6. **Выгоды.** История баллов и приветственные 1000; программы со скидкой, баллами и их сочетанием. Уровни с таймлайном, детали привилегий, закреплённое бронирование. Текущий уровень — белая карточка с кобальтовым левым акцентом. Отключения карты нет.
7. **Чаты.** Фото отелей, приоритет текущей/ближайшей поездки, непрочитанное, AI-подбор. В диалоге закреплённая шапка, пресет отправляется сразу, уведомления отеля открываются из колокольчика. Поиск/новый отель/блок поддержки на списке чатов удалены.
8. **Профиль и история.** Фото, путешественники, маска международного телефона, дата рождения/гражданство. История содержит предстоящую/завершённую/отменённую поездку; добавить пример `KEYS-2026`, скрыть бронь без отмены в отеле. Удаление аккаунта — подтверждающая шторка.
9. **Устройства и взаимодействия.** Повторить важные экраны на iPhone и Pixel: клавиатура, последняя строка под нижним действием, длинные названия, скролл внутри галереи/шторки, возврат к исходному экрану.

## Что считается готовностью

Рабочий основной путь и его ошибки, согласованные цвета/компоненты, отсутствие служебного текста в пользовательском потоке, сохранение состояния, подтверждённая визуальная проверка. Наличие кода или прохождение unit-тестов само по себе не закрывает визуальную приёмку.

[Спорные коммерческие вопросы](handoff/OPEN-QUESTIONS.md) вынесены отдельно: условия уровней/начислений, событие бонуса за друга, реальные программы отелей и будущие интеграции. Они не требуют повторно выбирать уже утверждённый дизайн.
