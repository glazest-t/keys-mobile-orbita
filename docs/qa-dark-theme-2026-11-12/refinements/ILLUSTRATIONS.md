# Иллюстрации для тёмной темы · 12.11.2026

Подготовлены отдельные PNG с настоящим alpha-каналом в app/public/brand/illustrations:
- trip-empty-portal-dark.png — пустое состояние поездок;
- hotelier-invite-card-dark.png — приглашение отельера;
- hot-deals-ticket-dark.png — скидки.

Использован встроенный ImageGen, редактирование исходников. Общий запрос: убрать белый фон и плоскость под объектом, сохранить композицию, материалы, надписи и метафоры, сделать чистый прозрачный PNG и читаемые светло-голубые акценты на тёмно-синем фоне. Для портала явно сохранён непрозрачный пейзаж внутри арки; для приглашения — надписи «Ключи / Закрытая версия»; для скидок — процент и огонь.

Подключение: theme-contrast.css, только тёмная тема (в том числе системная). Исходные светлые ассеты не заменены. Проверены alpha-каналы всех трёх файлов, визуально — пустая поездка и приглашение отельера. Фото номера и фотографии отелей не изменялись. Другие растровые слои онбординга уже имеют alpha, фон баннера истории ранее адаптирован отдельно.
