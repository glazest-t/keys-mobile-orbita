# Продукт и логика Ключей

Актуально на 30.10.2026. Мобильное приложение для выбора отеля, бронирования и управления проживанием. Четыре раздела: **Поездки, Найти, Чаты, Выгоды**; профиль открывается из аватара. «Ключи от всех отелей» — текущая формулировка бренда.

Полные действующие правила, переходы и источники реализации — [контракт мобильной версии](handoff/MOBILE-CONTRACT.md). Он заменяет ранний обзор итерации 1 там, где пользователь изменила поведение. [Функциональный DOCX](references/README.md) сохраняет исходную логику; более поздние решения пользователя имеют приоритет. Визуальный источник — текущий каталог экранов и брендбук 2.0.

## Роли и доступ

До авторизации доступны только вход/регистрация, приглашение, онбординг и условия. Поиск и остальные разделы мобильного приложения требуют входа. Обычный гость использует все пользовательские сценарии; подтверждённый отельер дополнительно получает Friendly Rate. Неподтверждённое приглашение сохраняет баннер подтверждения, но не даёт тариф. Отельер здесь — путешественник, не сотрудник с кабинетом управления гостиницей.

## Основные пути

1. Вход одним из шести демонстрационных сценариев → приложение.
2. Город → даты → гости → отель → номер/тариф → данные и услуги → оплата → поездка.
3. Предстоящая поездка → фактическое заселение отелем → ключ и проживание → день выезда → выезд отелем → оценка.
4. Услуга с известной ценой → заказ → оплата; ранний/поздний выезд после брони → сразу добавление с оплатой в отеле.
5. Пожелания или свайп → персональная выдача → избранное/бронь. Многошаговый опрос из пустых поездок убран.
6. Выгоды → баллы/операции/программа отеля → условия уровня → бронирование.
7. История поездок → просмотр, добавление по номеру или скрытие из приложения. Скрытие не отменяет бронь.

## Инварианты

- Цена, платёж, возврат и баланс используют общие расчёты, деньги в копейках. Снимок условий брони не изменяется задним числом.
- Кошельки отеля и Ключей раздельны. Оплата брони допускает максимум доступных баллов до 100% или без списания. В отдельной оплате услуги переключатель баллов убран.
- Friendly Rate только для подтверждённого отельера, без программы отеля, с баллами Ключей на бронировании. Обычный тариф остаётся доступен.
- Бронь, оплата и проживание имеют независимые состояния. Цифровой ключ только после заселения; онлайн-регистрации нет.
- Выезд подтверждает отель, гостю не нужен обязательный флоу подготовки. Депозит удалён из интерфейса, счёт доступен в деталях проживания по логике.
- Идемпотентность платежей, возвратов, выезда и начисления; данные разделены по владельцу и поездке.
- Уровень отеля зависит от квалификационной суммы, не от остатка баллов; условия новой брони сохраняются снимком.

## Реализация и границы

53 отеля, номера и тарифы, демонстрационные скидки и доступность; во всех отелях пример Friendly Rate −35%. Профили/поездки сохраняются локально. Настоящие SMS, оплата, замки, Wi-Fi, push, TravelLine и AI не подключены. Данные и типы: `app/src/state.ts`, `app/src/booking/model.ts`, `prototype/domain/`; будущая схема сервера ещё не определена.
