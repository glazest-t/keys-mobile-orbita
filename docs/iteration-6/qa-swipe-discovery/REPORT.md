# Проверка персонального порядка свайпа · P-035

27.10.2026. Проверка в отдельном профиле Chromium: данные открытого прототипа пользователя не изменялись.

## Проверено

- Лайк Mantera автоматически сохраняет её и поднимает «Маяк» выше «Соснового бора». Пропуск Mantera меняет порядок иначе — проверка домена.
- Текущая карточка и реакции сохраняются после reload. Другой профиль начинает независимо.
- Возврат из отеля после reload ведёт в прежний свайп. Общий поиск не изменяется.
- Нажатие по фото листает кадры без реакции; настоящий жест вверх пропускает отель. Ранее просмотренные не повторяются.
- Конец ленты сохраняется после reload. Подборка содержит лайкнутый отель, повтор запускается явно.
- Pixel 10: геометрия и кнопки; переход с reduced motion завершается корректно. Ошибок JavaScript нет.
- Граничные проверки: недоступные номера, бюджет, фильтр спа, изменение поиска, повторный callback, пропуск ранее сохранённого отеля, независимые пользователи.

Команды: `node --test tests/*.test.mjs`, `npm --prefix app run build`, `node scripts/verify-swipe-discovery.mjs`. 245 тестов; TypeScript/Vite и контроль 28 защищённых файлов прошли.

Исторические лайки до P-035 остаются в избранном, но не превращаются задним числом в ответы. Конец ленты использует существующий Empty и общие кнопки UI kit.
