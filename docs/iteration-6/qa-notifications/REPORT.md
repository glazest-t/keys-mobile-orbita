# Уведомления n2 · первый проход

28 октября 2026. Страница следует композиции исходного n2: шапка с «Прочитать все», горизонтальные категории, секции дат и общие карточки строк. Onest, кобальтовый акцент, мягкая подложка непрочитанных, зелёная плитка баллов. Ошибочные подписи true и онлайн-регистрация из исходного макета не перенесены.

Реализованы категории, пустые состояния, загрузка следующих 20 элементов, прочтение с сохранением, общий счётчик в колокольчике, сохранённые уведомления цены. Пять демонстрационных push-типов по рабочему листу источника доступны в «Уведомления · примеры»: отдельные пуши и набор для визуальной проверки истории. Данные владельцев разделены; будущие события отсекаются.

Переходы: инструкция → инструкция конкретной брони; ключ/welcome → поездка; отзыв → отзыв конкретной завершённой поездки с возвратом в историю; баллы → выгоды с возвратом. Недоступная, отменённая или чужая бронь не заменяется другой. Ключ не открывает дверь при клике по уведомлению и недоступен вне проживания.

Проверки: 302 теста, TypeScript/Vite, 28 защищённых файлов runtime. В браузере iPhone/Pixel проверены пустое состояние, набор из пяти типов, фильтр «Отель», прочтение всех, переход к отзыву/возврат, пуш инструкции/переход и внешний вид.

Ограничения: источник не требует историю для этих типов; примеры добавляются только вручную через инструменты. Автоматические отправки, фоновые таймеры, системные push, сообщения в чате и начисление баллов не подключены. Вопрос о целевой истории ожидает уточнения. Доступность отзыва в день выезда из таблицы не переносилась: текущая согласованная реализация разрешает отзыв после выезда.


28.10.2026 · Уточнение P-037: справа в закреплённой шапке чата — звонок и уведомления отеля. Звонок через tel показывается только при собственном телефоне в hotelContacts.ts; для Mantera проверен +7 800 101 33 33 на https://manteracongress.ru/booking, другим отелям контакт не подставляется. Колокольчик открывает все категории уведомлений выбранного отеля; hotelId сохраняется в новых примерах, старые связываются по доступной брони, ценовые — по своему черновику. «Прочитать все» действует только в текущем контексте отеля. Возврат восстанавливает чат исходной брони и предыдущий путь. ИИ-ассистент и среднее время ответа сохранены. Проверены 6 тестов уведомлений, build/runtime и браузерная цепочка чат → уведомления → отзыв → уведомления → чат → поездки. Звонок фактически не совершался.
