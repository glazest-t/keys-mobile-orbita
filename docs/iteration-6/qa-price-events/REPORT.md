- «Прочитать все» снимает непрочитанные с двух событий; после reload обе записи остаются прочитанными.
- Ошибок консоли в проверенной сессии нет.

## Границы

Локальная демонстрация без внешних push, мониторинга и реальной оплаты. Другие типы уведомлений ещё не реализованы. Цены в истории — снимки на момент события; переход использует актуальную цену. Изменение действует на сочетание владельца, номера, тарифа, дат и гостей. Отдельный визуальный предпросмотр карточек не меняет расчёты.
