# Онбординг после регистрации отельера

29.10.2026. Встроенный браузер, мобильный режим iPhone, localhost:5173.

## Результат

После регистрации по приглашению отельера показываются существующие три экрана онбординга с исходными иллюстрациями и переходами. Завершение продолжает выбранную ветку без повторного ввода телефона.

## Проверено

- Принять приглашение → телефон → СМС → имя → заставка → три экрана → «Продолжить» → рабочий email для подтверждения статуса.
- Пропустить подтверждение → телефон → СМС → имя → онбординг → «Продолжить» → «Поездки». Баннер «Статус отельера ожидает подтверждения» сохранён.
- Перезагрузка во время второго сценария восстанавливает онбординг; регистрация и выбранная ветка не теряются.
- Финальный экран не предлагает повторный вход; кнопки «Продолжить» и «Назад» помещаются в мобильном холсте. Прежняя композиция и анимация сохранены.
- 35 тестов hotelier/demo-entry/auth прошли: две ветки, сохранение/восстановление, очистка завершённого перехода и отсутствие изменения обычной регистрации.
- Сборка прошла; проверка 28 защищённых runtime-файлов прошла.

## Уточнение порядка экранов · 29.10.2026

Текущий порядок заменяет описанный выше первоначальный: общая заставка → приглашение → телефон/СМС/имя → подтверждение статуса → онбординг → поездки. При пропуске подтверждения — онбординг перед приложением с ожидающим баннером. Первая заставка теперь общая для всех сценариев входа и запуска приложения; между регистрацией, подтверждением и онбордингом её нет.

Проверено в IAB: сценарий 2 от стартового ключа до приглашения, регистрация, отправка запроса на вымышленный email, демонстрационный ответ «подтвердить запрос», онбординг без повторной заставки, «Поездки» с подтверждённым статусом. Снимок [онбординга после статуса](after-status-onboarding.jpg). Дополнительно проверены заставка → телефон обычного пользователя, заставка → четыре поля PIN и запуск биометрии через общую заставку. Дизайн приглашения и иллюстраций не менялся.

36 тестов hotelier/demo-entry/auth прошли, включая порядок подтверждение → онбординг и отсутствие повторного тура при подтверждении из профиля. Сборка и проверка 28 защищённых файлов прошли.
