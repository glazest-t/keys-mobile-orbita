# История поездок, помощь и путешественники · 28.10.2026

P02–P06/P11–P14. История следует карточке p3 «Все экраны», подробности — существующим d1/x2, помощь без собственного HTML-макета использует общие Row/C5, Field, BottomSheet и Button.

## Реализовано

- Поиск по отелю/городу, фильтры завершённых/отменённых, сортировка от новых дат. Поездки берутся из общего сохранённого состояния и проверяются по доступу, активные не попадают в архив. Поддерживаются свои поездки и доступ «Управление». Поиск и фильтр сохраняются при возврате.
- Прошлая поездка: фото, даты, гости, категория, сумма; для отменённой — фактический возврат и удержание. Короткий отзыв 1–5/1500 символов можно менять; существующие фото и финансовые данные сохраняются. Сводка скачивается текстом, не чеком. Повтор ведёт в нужный отель и возвращает к истории.
- Помощь: 8 статей по утверждённой логике, поиск/темы/пустое состояние, переходы в соответствующие разделы. Поиск сохраняется при возврате. Связь с отелем использует чат доступной брони и возвращает в помощь.
- Поддержка «Ключей»: тема, необязательная поездка, сообщение 10–2000 символов, локальный номер/статус и список обращений. Вход из истории подставляет поездку; черновик сохраняется по пользователю. Повтор не дублирует запрос. Нет реальной отправки оператору, пояснение в инструментах демонстрации.
- Путешественники: проверены создание/редактирование/сохранение при уходе/ошибка будущей даты/удаление дополнительного человека. Исправлены выбор редактируемого человека и возвраты в исходный список. Временная Ирина Примерова после проверки удалена.
