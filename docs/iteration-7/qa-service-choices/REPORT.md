# M4 · Состав заказа услуг

28.10.2026. Функциональная основа U02/U03/U05, визуальная — sv1/sv2, существующие строки C5 и шторка заказа/оплаты. Новая иллюстрация не требуется: используются исходные иконки.

Добавлены меню еды (5 категорий, 8 демонстрационных позиций), корзина с количеством 0–10, дата/время доставки, состав оплаченного заказа. Уборка: стандартная/вечерняя/экспресс. Предметы: полотенца, бельё, гигиенический набор с количеством. Подушки: пуховая/латексная/с гречихой. Другой запрос: описание, желаемое время, локальное фото, ожидание и отмена. Цены меню — рабочие демоданные, не реальные предложения отелей.

Платный заказ сразу открывает существующую оплату без баллов и депозита; СБП по умолчанию. Бесплатный не создаёт платёж. Произвольный запрос не объявляет неизвестную стоимость бесплатной. Состав сохраняется снимком в ServiceRequest, оплата/возврат/история общие, дубликат ID не создаёт заказ.

## Проверено

- 328 доменных/auth-тестов прошли. Новые тесты проверяют сумму 1690 ₽ (2 пасты и чай), пустой/неизвестный/дробный состав, доступ/даты, однократную оплату/возврат, бесплатные предметы и произвольный запрос.
- iPhone: меню → категории → несколько позиций → корзина → оплата СБП → «Оплачено» → отмена с возвратом 1690 ₽ → шторка закрыта и системный хинт. Уборка и предметы сохраняют выбранный состав без оплаты. Пустое описание запроса показывает ошибку; ввод → отправка одним нажатием с открытой клавиатурой → ожидание.
- Pixel: подушка → латексная → заказ → правильное название и бесплатная стоимость; кнопки и итог помещаются.
- Визуально исправлены отсутствующая иконка минуса и сжатие строк корзины. Содержимое прокручивается над нижним итогом.
- Файл фото использует уже проверяемый общий readProblemPhoto; системный выбор файла в этом проходе повторно не проверялся.

Также исправлены демонстрационные отзывы некурортных отелей: больше нет чужих упоминаний моря и Олимпийского парка. Темы/подпись отзывов формируются из соответствующего набора.
