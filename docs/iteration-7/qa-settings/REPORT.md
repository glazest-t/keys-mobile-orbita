# Настройки профиля · 28.10.2026

P07–P10, P15–P16 собраны по функциональному DOCX на компонентах p6 «Все экраны». Источник: docs/brand/reference/profile-p6.html.

## Реализовано

Каналы push/email/SMS, темы, тихие часы 22:00–08:00 с редактированием; отдельный переход в историю уведомлений. Без почты предлагается основной путешественник, возврат сохраняет источник. Время получает маску ЧЧ:ММ и проверку диапазона.

Демонстрационные настройки биометрии, установка/повтор/изменение/отключение PIN, текущий и пример другого сеанса, завершение остальных с подтверждением. Хранится только признак PIN, не введённые цифры. Нет настоящей блокировки/отзыва токенов.

Персонализация, аналитика, запрос удаления с явным подтверждением и отменой. Запрос сохраняется как флаг, данные/брони фактически не удаляются. Пояснение симуляции находится в инструментах вне телефона. Настройки изолированы по аккаунту.

## Проверка

В браузере: переходы профиль → настройки → назад; отсутствие email → данные → возврат; неверное время → исправление → сохранение → перезагрузка; несовпавший PIN → повтор → успех → отключение; завершение чужого сеанса сохраняет текущий; запрос удаления → отмена. 4 доменных теста покрывают изоляцию, сохранение, валидацию и отсутствие секретов/удаления данных.
