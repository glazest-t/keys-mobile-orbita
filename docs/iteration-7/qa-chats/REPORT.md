# M3 · Чаты и уведомления

28.10.2026. Реализованы C01–C03, повторно проверены N01–N02. Визуальная основа ch1/ch2 и общие компоненты; шапка диалога сохраняет позднее утверждённое решение пользователя.

## Что работает

Список разделён на диалоги по поездкам и остальные. Поиск, пустое состояние, выбор отеля по имени/городу/району, новый диалог без брони. Переписка и черновики разделены по владельцу и отелю; существующие диалоги по bookingId сохранены. Пресеты отправляются одним нажатием и не стирают набранный черновик. Ответ приходит и после ухода из диалога, появляется счётчик непрочитанного, открытие снимает его. Повторный ответ не создаётся.

Запрос сотрудника — локальное состояние ожидания, без имитации подключившегося человека. ИИ-ассистент явно подписан. Реальная отправка, оператор и статистика времени ответа не подключены.

## Проверки

- 324 доменных/auth-теста: прошли. Пять новых проверок охватывают изоляцию владельцев, права управления, сопоставление отеля и брони, повторную отправку/ответ, независимое прочтение, отсутствие финансовых изменений.
- Браузер: пустой поиск → Казань → отдельный диалог → пресет → выход → непрочитанный ответ → прочтение. Отель из сообщения → возврат в тот же чат. Уведомления отеля → возврат в тот же чат. Поддержка из списка → назад в чаты. Черновик не теряется при пресете.
- iPhone и Pixel: список, пустой поиск, диалог, длинное название, кнопки звонка/уведомлений, нижняя панель; горизонтального переполнения не видно. Свежая QA-вкладка не показала console errors.
- N01/N02: проверены существующие ограничения времени/владельца, недоступная бронь/ключ/отзыв и возврат. Пять демонстрационных push остаются примерами из таблицы, не реальными событиями начисления.
