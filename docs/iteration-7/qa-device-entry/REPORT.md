# Сценарии входа 5 и 6

29.10.2026. В панель демонстрации добавлен готовый вход по PIN (1234) и биометрии. Настраивать доступ заранее не требуется. Используется отдельный тестовый профиль Анны; личные PIN, роли, профили и брони не перезаписываются. При повторном выборе используется тот же демопрофиль.

Биометрия: успех, ошибка распознавания, недоступность. Ошибка и недоступность предлагают основное действие «Ввести PIN-код»; при ошибке также доступен повтор. Ввод верного PIN открывает приложение автоматически.

Проверки: 19 тестов demo-entry/profile-settings; production build и целостность 28 защищённых файлов runtime. Браузерный сценарий: scripts/verify-device-entry.mjs. Иллюстрации состояния: pin-entry.png, biometric-failure.png. Реальной биометрии и серверной авторизации нет.
