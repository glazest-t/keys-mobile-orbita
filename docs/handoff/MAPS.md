# Карты 2ГИС · 2 ноября 2026

## Подключение

Общий `app/src/maps/TwoGisMap.tsx` использует официальный `@2gis/mapgl` и SDK v1. `HotelMap` соединяет координаты с текущими предложениями: фильтры, цены и избранная подборка берутся из состояния приложения. Метка выбирает карточку отеля, карточка открывает детали. Карта поддерживает перемещение, масштабирование, загрузку, ошибку и повтор. Логотип и атрибуция 2ГИС сохранены.

Карты заменяют схемы в выдаче и её развёрнутом виде, избранном, расположении отеля, разделе мест рядом и предпросмотре маршрута. В развёрнутом виде карта владеет жестами; компактные превью не перехватывают прокрутку. Защищённый мобильный runtime не изменён.

## Настройка ключа

Локально: `VITE_2GIS_MAP_KEY` в игнорируемом `app/.env.local`; шаблон — `app/.env.example`. В GitHub Actions используется одноимённый repository secret, передаваемый шагу сборки Pages. После смены ключа требуется новая сборка. Значение не хранится в исходниках или документации.

Это браузерный SDK: ключ виден в запросах и готовой сборке. В кабинете 2ГИС следует ограничить его разрешёнными доменами проекта (`glazest-t.github.io`, локальные адреса для разработки) и необходимыми API. Доступ к кабинету и настройки лимитов не менялись.

## Координаты и ограничения

`spec/map-locations.json` содержит 34 сопоставленных реальных объекта: 18 в Москве, 15 в Санкт-Петербурге и Mantera Resort & Congress. Координаты получены по названию и адресу через API 2ГИС и проверены на соответствие каталогу. У каждого объекта сохранены ссылка на карточку источника, адрес, исходное название и дата проверки. Порядок координат: долгота, широта.

19 объектов не нанесены: 12 вымышленных и 7 без однозначного соответствия. Нельзя ставить такой отель в центр города или переносить координаты одноимённого объекта. Уведомление о неполном покрытии на карте скрыто по запросу пользователя; отели без координат остаются доступны в списке. Если у карты нет ни одной известной точки, остаётся состояние «Адрес отеля уточняется».

## Оформление карты «Ключи» · 02.11.2026

Единая светлая 2D-подложка применяется во всех картах через `styleOptions` официального MapGL API. Файл `app/public/maps/keys-light.json` хранится вместе со сборкой: фон #F4F3FA, кварталы #ECEBF3, вода #D6E3F3, зелень #DDEAE4, здания #DEDEE9, дороги белые с серо-лавандовыми границами, подписи #555B70. Убраны текстуры воды/леса, 3D-декор и большинство коммерческих POI; сохранены улицы, метро, остановки, вокзалы и ориентиры. Шрифты географических подписей — штатные Noto из MapGL, метки цен и управление — Onest.

Обычная метка белая; скидка действующего предложения — фуксиевый процент и мягкая розовая подложка; выбранный отель всегда кобальтовый. Процент берётся из расчёта конкретного предложения, а не из общего признака отеля. Friendly Rate не выдаётся за обычную скидку. Цена и расчёт бронирования не менялись. Атрибуция 2ГИС остаётся видимой, CSS-фильтр на карту не применяется.

Тема подготовлена на основе официального стиля `c080bb6a-8134-4993-93a1-5b4d8c36a59b`, проверенного 02.11.2026. Для повторной генерации из свежего JSON-ответа стилей: `python3 scripts/style_2gis_map.py /path/to/base-style.json` из корня. Используются штатные CDN шрифтов и иконок 2ГИС. Стиль хранится локально и не создан как проект в кабинете пользователя. После обновлений SDK или источника карт нужно проверять совместимость и при необходимости пересобирать стиль — это требование MapGL для самостоятельно хранимых стилей. Сам ключ не записан в файл темы.

## Места рядом · 2 ноября 2026

- `spec/nearby-places.json`: 34 отеля, 270 связей «отель–место», 240 уникальных мест; до 8 мест на отель. Радиус — расстояние от координат отеля до точки места, дополнительно проверенное после ответа API. Это радиус по карте, а не обещание пешего пути не более 1500 м. Снимок доступен без запросов каталога при каждом открытии.
- Названия, категории, координаты и ссылки — Places API. Из выдачи исключены служебные объекты и безымянные точки. Короткие описания сокращены из `items.description`, если доступны (`aboutSource=2gis`); иначе используется нейтральный текст категории, без выдуманных часов работы, цен или исторических фактов.
- Routing API проверен реальным запросом `transport=walking`, `output=summary`: возвращает `length` и `duration`. После серии запросов ключ начал возвращать HTTP 429, `too many requests`. В текущем снимке минут нет: показывается «≈ N м» (расстояние по радиусу, не длина пешего маршрута). При доступном ответе карточка автоматически покажет длину маршрута и «≈ N мин пешком». Нужно повторить обновление после восстановления лимита; тариф API не менялся.
- `spec/nearby-photos.json`: 25 проверенных фото Wikimedia Commons с URL страницы файла, автором и лицензией. Places API не предоставляет фотографии. По новому запросу пользователя там, где фото нет или оно не загрузилось, используются сгенерированные тематические иллюстрации с короткой подписью «Иллюстрация». Подробности и промпты — [NEARBY-ILLUSTRATIONS.md](NEARBY-ILLUSTRATIONS.md).
- Карта, список, категории и BottomSheet используют одни места. Метки с одинаковыми координатами разнесены в пикселях без изменения геоданных. В карточке остаётся «Понятно»; маршрут отдельной кнопкой не возвращается.
- У 19 отелей без подтверждённых координат места не подставляются из центра города или другого отеля; показывается пустое состояние.

### Обновление снимка

`python3 scripts/refresh_nearby_2gis.py` читает ключ из окружения или игнорируемого `app/.env.local`. До 3 поисков и 8 маршрутов на отель; ответы кэшируются на день в системной временной папке. При HTTP 429 маршруты больше не запрашиваются в этом запуске. Уже полученные за тот же день маршруты сохраняются для неизменённых точек. `--skip-routing` обновляет только места. Ошибка поиска не затирает прежний снимок; замена JSON атомарная. Фото ведутся отдельным редакторским реестром.

Для production потребуется серверное обновление с лимитами и мониторингом. Текущая версия — снимок для браузерного прототипа. Геоданные и маршруты реальные. Фото Commons документальные, остальные изображения — демонстрационные иллюстрации; цены и бронирования по-прежнему демонстрационные.

Источники: [Places API](https://docs.2gis.com/en/api/search/places/overview), [ограничения фотографий](https://docs.2gis.com/en/api/search/places/examples/filtering), [Routing API](https://docs.2gis.com/en/api/navigation/routing/overview).

Уточнение интерфейса 02.11.2026: номера убраны из карточек списка; расстояние без маршрута обозначается символом ≈. В деталях восстановлен блок «Почему вам может понравиться» с условным пояснением по категории, без заявления об анализе истории пользователя.
