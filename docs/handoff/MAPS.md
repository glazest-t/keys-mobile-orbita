# Карты 2ГИС · 2 ноября 2026

## Подключение

Общий `app/src/maps/TwoGisMap.tsx` использует официальный `@2gis/mapgl` и SDK v1. `HotelMap` соединяет координаты с текущими предложениями: фильтры, цены и избранная подборка берутся из состояния приложения. Метка выбирает карточку отеля, карточка открывает детали. Карта поддерживает перемещение, масштабирование, загрузку, ошибку и повтор. Логотип и атрибуция 2ГИС сохранены.

Карты заменяют схемы в выдаче и её развёрнутом виде, избранном, расположении отеля, разделе мест рядом и предпросмотре маршрута. В развёрнутом виде карта владеет жестами; компактные превью не перехватывают прокрутку. Защищённый мобильный runtime не изменён.

## Настройка ключа

Локально: `VITE_2GIS_MAP_KEY` в игнорируемом `app/.env.local`; шаблон — `app/.env.example`. В GitHub Actions используется одноимённый repository secret, передаваемый шагу сборки Pages. После смены ключа требуется новая сборка. Значение не хранится в исходниках или документации.

Это браузерный SDK: ключ виден в запросах и готовой сборке. В кабинете 2ГИС следует ограничить его разрешёнными доменами проекта (`glazest-t.github.io`, локальные адреса для разработки) и необходимыми API. Доступ к кабинету и настройки лимитов не менялись.

## Координаты и ограничения

`spec/map-locations.json` содержит 34 сопоставленных реальных объекта: 18 в Москве, 15 в Санкт-Петербурге и Mantera Resort & Congress. Координаты получены по названию и адресу через API 2ГИС и проверены на соответствие каталогу. У каждого объекта сохранены ссылка на карточку источника, адрес, исходное название и дата проверки. Порядок координат: долгота, широта.

19 объектов не нанесены: 12 вымышленных и 7 без однозначного соответствия. Нельзя ставить такой отель в центр города или переносить координаты одноимённого объекта. На карте показывается уведомление о неполном покрытии, а отели остаются доступны в списке.

Реальные объекты, которым требуется точный адрес:

- `moscow-apart-otel-okruzhnaya`
- `moscow-otel-gettsleep-sheremetevo-terminal-aeroekspress`
- `spb-apartamenty-new-horizon-liteyniy`
- `spb-apartpeydzh-elagin`
- `spb-apartamenty-dvoriki-petra-na-gorohovoy`
- `spb-greenwich-by-friends`
- `spb-mini-otel-moov-apart-bogema`

Карточки ближайших мест, расстояния и оценки времени маршрута пока демонстрационные. На реальную карту нанесён отель, вымышленные места не отмечены. Routing API не подключён. Кнопка 2ГИС в маршруте открывает найденную карточку отеля во внешнем сервисе; построение маршрута доступно там. Геолокация пользователя не запрашивается. Цены и доступность номеров остаются демонстрационными данными приложения, не данными 2ГИС.
