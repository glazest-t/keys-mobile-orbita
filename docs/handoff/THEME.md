# Темы интерфейса

12.11.2026 — добавлена тёмная тема по запросу пользователя.

- Единый выбор: «Светлая», «Тёмная», «Как на устройстве».
- Точки входа: настройки прототипа → «Тема оформления»; профиль → «Настройки аккаунта» → «Тема оформления».
- Выбор сохраняется в `localStorage` (`keys-orbita-theme`). Параметр ссылки `theme=light|dark|system` имеет приоритет. Переключение обновляет параметр, сохраняя остальные настройки и маршрут.
- Настройка независима от Полный/Ноябрь, набора иконок и варианта текста. По умолчанию — светлая тема. Системный режим реагирует на изменение `prefers-color-scheme` без перезагрузки.
- Обе точки входа используют один модуль `app/src/appTheme.ts` и `useAppTheme`. Десктоп импортирует те же компоненты.

## Дизайн и разработка

Палитра в `app/src/theme.css`, активатор — `html[data-app-theme="dark"]`. Компоненты используют семантические переменные с прежними светлыми значениями в fallback; геометрия, шрифты, тексты и логика экранов не менялись. Тёмные фоны: `#101722` / `#192333`, текст `#f0f4fc`, вторичный `#b4c1d6`, ссылки `#91b0ff`. Синий цвет основных кнопок сохранён. Статусы различаются цветом и содержанием.

Для новых компонентов использовать `--k-surface-app`, `--k-surface-card`, `--k-text-primary`, `--k-text-secondary`, `--k-border-subtle`; цвет ссылок — `var(--theme-link,var(--k-action-primary))`. Белый текст на основных кнопках не заменять цветом основного текста. Не инвертировать фотографии и весь экран.

Служебные элементы телефона, шторки, поля и клавиатура адаптированы внешними стилями, без изменения защищённого runtime. Для десктопной формы поиска подготовлен отдельный SVG с тёмной палитрой. Фотографии, документы и географическая подложка 2ГИС сохраняют собственные цвета.

## Проверка

- TypeScript мобильной и десктопной версии; production-сборки обеих версий.
- 521 тест, в том числе приоритет URL/сохранённой настройки и системная тема; целостность 28 защищённых файлов runtime.
- В браузере: профиль, оба переключателя, сохранение после перехода на URL без `theme`, светлый/тёмный/системный режимы; мобильные поиск, календарь, поездки, детали брони; десктопные поиск, выдача, отель, оформление брони, профиль/окно темы, выгоды.
- На GitHub эти изменения пока не опубликованы.
