# Иллюстрации мест рядом · 2 ноября 2026

По прямому запросу пользователя созданы примерные фотографии для прототипа. Это вымышленные тематические изображения, а не фотографии названных объектов 2ГИС. Реальные фото Wikimedia Commons имеют приоритет; при отсутствии или ошибке загрузки используется иллюстрация категории. В деталях она подписана «Иллюстрация». Координаты, названия и расстояния остаются реальными.

Инструмент: встроенный ImageGen, создание новых изображений без референсов. Исходные PNG сохранены без изменения; 3:2, центральная композиция для широкого кадра и миниатюры.
