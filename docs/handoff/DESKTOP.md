# Десктопная версия

03.11.2026 пользователь разрешила публикацию десктопного прототипа вместе с мобильным.

- `/desktop/` — десктопная версия, открытый поиск, оформление после входа.
- `/prototype/` — мобильная версия, вход обязателен.
- `/desktop/review.html` — просмотр текущих сценариев десктопа.
- Настройки «Сценарии» → «Версия прототипа» сохраняют маршрут и выбранный пример при переключении.

Исходники десктопа находятся в `desktop/`, общие компоненты и бизнес-логика — `app/src/` и `prototype/domain/`. Мобильный runtime не заменяется; десктоп собирается со своим адаптером полей, прокрутки, диалогов и навигации. Старые макеты не публикуются.

Локальный запуск: `npm --prefix app ci`, `npm --prefix desktop ci`, `npm --prefix desktop run dev`. Сборка сайта: `npm --prefix app run build:pages`. GitHub Actions собирает обе версии одним выпуском. Ключ карты берётся из GitHub secret VITE_2GIS_MAP_KEY для обеих сборок.

В Pages мобильная и десктопная версии используют общий origin, поэтому доступны одни и те же сохранённые демонстрационные данные. Смена версии не переносит несохранённое состояние формы. Каталожные примеры имеют изолированные данные. Локально порты 5173/5180 разделяют хранилища.

Оплата, SMS, биометрия, ключ и ответы отеля остаются демонстрационными. Публикация не подключает реальные платежи.
