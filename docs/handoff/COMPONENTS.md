# Компоненты, состояния и визуальный контракт

30.10.2026. Живые примеры — `http://127.0.0.1:5173/#kit`. В примерах используются компоненты приложения; демонстрационные действия не меняют брони и кошельки.

## Основа

Onest 400/500 — интерфейс; Unbounded 500 — акцентные заголовки и суммы. Кобальт `#2F5BFF`, светлая подложка `#EEF0FF`, фон `#F4F5FB`, основной текст `#101320`, вторичный `#5A6072`, линии `#E4E7EF`. Цвета состояния берутся из токенов и `StatusBadge`, не создаются отдельно для каждого экрана. Избранное — `#E84D7A`. Слоган: **«Ключи от всех отелей»**.

Основная кнопка 52 px, радиус 16; компактные действия сохраняют удобную зону нажатия. Карточки 22/28 px по конкретному макету; не заменять все одним универсальным радиусом. Плотность, фотографии и положение цены берутся из текущих компонентов приложения, показанных в живом каталоге «Все экраны». Архивные HTML-референсы не являются действующей спецификацией.

## Где брать компонент

Все пути ниже относительно `app/src/`.

| Компонент / источник | Данные и события | Состояния и ограничения |

| `SmsCodeField.tsx` | value, onChange, error, success | СМС 6 ячеек, PIN 4; вставка, переход между ячейками, удаление, masked PIN; success общий мятный |

## Статусы

| Смысл | Подпись | Вид |
|---|---|---|
| Ранний заезд / поздний выезд добавлен | Добавлено | success + check; даже если бухгалтерский заказ уже исполнен/оплачен |
| Платная услуга ожидает оплаты | К оплате | warning + pending |
| Платная услуга оплачена | Оплачено | success + check |
| Бесплатная услуга принята | Заказано | success + check |
| Нужен ответ по произвольному запросу | Ждёт ответа | warning + pending |
| Отклонено | Отклонено | error + close |
| Отменено | Отменено | neutral + close |
| Уровень программы | Ваш уровень | success + check |

В деталях брони список услуг не дублирует все эти статусы: пользователь отдельно попросила убрать там «Выполнено/Оплачено» и даты. Отмена услуги закрывает окно и даёт Toast. Статус не должен заменять основное действие оплаты.

## Уровень отеля: окончательный выбранный вид

Таймлайн сохранён. Текущая карточка **белая**, слева кобальтовый акцент 5 px, кобальтовое название, мягкая тень. Статус зелёный. Это вариант 3 и он заменяет сплошную синюю и мятную версии. Список не показывает количество привилегий; подробности доступны в шторке. Не фиксировать высоту и не обрезать название отеля/уровня. Кнопка бронирования вынесена в общую нижнюю панель.

## Навигация, прокрутка и safe area

Шапки страниц прокручиваются с содержимым. Исключение — шапка диалога с кнопкой назад, закреплённая по отдельному решению пользователя. Нижнее меню — четыре раздела с двигающейся подложкой, без точки. Колокольчик — индикатор новых событий без числового счётчика.

Нижние действия бронирования/услуг/программы отеля размещаются вне MobileScroll, контент получает отступ под реальную высоту панели и safe area. Шторки — в портале; при показе скрывается клавиатура. Статусная строка и навигационная зона устройства принадлежат runtime. На подтверждении бронирования применяется `page-scroll`, чтобы success не попадал под системную строку.

## Движение

Источник общих значений: `interactions.tsx` и `interactions.css`; онбординг отдельно `onboarding/motion.ts` (D-011). [Таблица брендбука](../brand/motion.json) различает реализованное движение и нативные справочные эффекты.

| Событие | Текущее значение / поведение |
|---|---|
| Заставка | 2400 мс, один ключ/орбита перед каждым входом; биометрия объединена с ней |
| Биометрия / успех | authCheckMs 900, authSuccessMs 420; результат на той же заставке; ошибка ведёт к PIN |
| Открытие двери | keyOpeningMs 1100; keySuccessHoldMs 3000; повтор блокируется до завершения |
| Оплата | paymentWaitMs 800 — демонстрационная задержка, не требование к платёжному API |
| Карта вперёд / назад | push .46 / pop .38; iosPush [.32,.72,0,1] |
| Баллы | 1,4 с, орбита и счётчик; анимация сама не начисляет деньги/баллы |
| Предпочтения | bubbleAppear .52, stagger .045, orbit 1.1; водные кольца при выборе |
| Вкладка / тост | .2 / .3 с; toast показывается 2,6 с |
| Онбординг | 600 мс opacity / 800 мс transform; слои 2-го шага с разных сторон, 3-й собирает источники и карточки |

Orbit easing [.65,0,.35,1], arrive [.2,.8,.2,1]. `prefers-reduced-motion` отключает пространственные эффекты, сохраняя результат. Пружины защищённых BottomSheet/клавиатуры — реализация runtime; не выдавать целевые миллисекунды исходного каталога за точную физику браузерной шторки. Нативная хаптика в браузере не реализована.

## Приёмка нового компонента

Проверить длинный текст, отсутствие необязательных выгод, нулевые балансы, disabled/loading/error/success, область нажатия, клавиатуру, вертикальный жест внутри карусели и последнее действие над нижней панелью. Визуальную проверку выполнять на обоих пресетах телефона. Обновить матрицу и QA ссылкой на реальный результат; не отмечать экран проверенным только по наличию файла.
