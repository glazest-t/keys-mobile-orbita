## Возможности браузера

Браузер не перечисляет установленные приложения карт. Шторка показывает доступные ссылки провайдеров: Яндекс Карты, 2ГИС, Google Карты; Apple Maps на устройствах Apple. Ссылка передаёт координаты отеля, запуск приложения или веб-версии зависит от устройства и настроек. Реальная установка карт не имитируется. Для нативного мобильного клиента фильтрацию установленных приложений необходимо реализовать средствами платформы.

Web Share открывает системный выбор получателя при поддержке браузером и безопасном контексте. Если API недоступен, есть копирование ссылки и сама ссылка. Закрытие системного окна ничего не отправляет. Встроенный браузер проверен для резервного интерфейса; открытие системных окон и внешних приложений на физическом телефоне требует проверки после публикации по HTTPS.

Источники схем: [Web Share](https://www.w3.org/TR/web-share/), [ссылки 2ГИС](https://help.2gis.ru/question/razrabotchikam-zapusk-ideystviya-vmobilnom-prilozhenii-cherez-deeplink), [Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started), [Apple Map URLs](https://developer.apple.com/documentation/mapkit/unified-map-urls).
