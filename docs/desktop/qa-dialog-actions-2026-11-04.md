# Десктопные попапы: действия в одну строку

04.11.2026. Локальная версия 5180, мобильная регрессия 5173. На GitHub в рамках этой правки не опубликовано.

## Реализация

- Общий DialogActions группирует соседние завершающие действия, включая условно появляющиеся кнопки. Мобильный вывод остаётся фрагментом.
- DesktopDialogContext задаётся оболочкой десктопного диалога. Button использует в ней только primary/secondary.
- Кнопки выровнены слева (последнее уточнение пользователя от 04.11.2026), в одном ряду, одинаковой высоты. Для длинных групп окно расширяется в пределах viewport.
- Убрано отдельное красное оформление подтверждения отмены брони. Названия и обработчики действий сохранены.
- Элементы выбора внутри формы (гражданство, способы оплаты, загрузка фото) не превращаются в завершающие действия.

## Проверка

- Каталог: 151 из 151 сценария открылся без ошибки воспроизведения. Включая ручное открытие даты рождения, проверено 43 диалога; переполнения ширины и кнопок ghost/danger нет.
- Детальный браузерный проход при 1024 × 800: отмена брони, удаление наблюдения, оплата услуги, заказ услуги, Wi-Fi, дата рождения, несохранённые изменения, выход, фото профиля без фото и с фото (три действия).
- Проверены координаты кнопок в каждой группе, одинаковая высота, размещение внутри контейнера и цвет primary. Проверены отмена выбора даты, сохранение введённых данных при продолжении редактирования, закрытие выхода и Escape.
- Мобильный выбор даты: прежняя вертикальная компоновка и ghost-кнопка отмены, без дополнительной обёртки.
- Визуально проверены дата рождения и окно с тремя действиями при несохранённых изменениях.
- TypeScript, production-сборка десктопа и контроль 28 защищённых файлов мобильного runtime пройдены.
