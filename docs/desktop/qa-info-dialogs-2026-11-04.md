# Информационные окна десктопа · 04.11.2026

Убраны кнопки, которые только закрывают окно: оснащение номера, детализация цены, сведения об отеле, уровни/баллы/привилегии, места рядом, просмотр услуг и подтверждения завершённых действий. Крестик в общей шапке, Escape и возврат фокуса сохранены. Пустые панели действий не занимают место. Кнопки редактируемых форм, выбора тарифа, платежей, заказов и отмены не удалены. Мобильный интерфейс сохранён.

Явный признак `dismissOnly` используется общим Button только внутри DesktopDialogContext. Скрытие по тексту, DOM-поиск и удаление элементов не применяются.

Проверки: 9 браузерных сценариев — оснащение, тариф, цена, правила баллов, уровень отеля, заказ услуги, Wi-Fi, сохранение даты рождения, мобильное оснащение. Во всех информационных окнах проверено закрытие крестиком; целевые действия остаются видимыми, ошибок JavaScript нет. Оснащение дополнительно просмотрено в in-app browser. Скрипт: `desktop/scripts/qa-info-dialogs.mjs`, локальные артефакты: `.desktop-work/qa/info-*`.
