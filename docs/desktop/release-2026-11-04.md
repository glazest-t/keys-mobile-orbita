# Публикация мобильной и десктопной версий · 04.11.2026

Обновление подготовлено поверх опубликованного коммита `0566aed`. Включены текущие исходники обеих версий, фото и каталог услуг, общая логика заказа/отмены и оплаты в отеле, адаптивные шторки, подписи на странице поездки, компактные счётчики меню, десктопные попапы и исправления внутренних страниц. Архивные дизайн-варианты не возвращаются. Маркетинговый комплект остаётся в существующем GitHub Release.

Проверки release-checkout: 432 теста, обе production-сборки, 28 защищённых runtime-файлов; brand/product validators; 2107 ссылок/ресурсов, 151 состояние каталога; 2643 ссылки/файла маркетингового раздела. Все проверки прошли. Выпуск содержит ранее выполненную визуальную проверку услуг в браузере; отчёты находятся рядом с этим документом.

Адреса после публикации: https://glazest-t.github.io/keys-mobile-orbita/prototype/ и https://glazest-t.github.io/keys-mobile-orbita/desktop/ . Платежи и заказы — демонстрационные.
