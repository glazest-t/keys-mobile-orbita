# Десктопный поиск — окна под полями

8 ноября 2026. Реализация: `app/src/desktop/DesktopSearchBar.tsx`, `desktop/src/search-popover.css`.

## Поведение

- Общая форма на «Найти» и в результатах. Город/отель, даты и гости редактируются без модального затемнения и перехода на другую страницу.
- Одновременно открыто одно окно. Поле подсвечивается. Данные сохраняются при переключении и закрытии окна в текущей форме; поиск применяется кнопкой «Найти».
- После выбора направления открываются даты, после допустимого диапазона — гости. Два месяца рядом, выбор между месяцами. При незавершённом диапазоне повторное открытие продолжает выбор выезда.
- Escape и крестик возвращают фокус на поле; клик снаружи закрывает окно. Высота ограничена доступной частью экрана.
- Для конкретного отеля кнопка «Найти» открывает его детали с выбранными параметрами.
- Мобильная форма сохраняет собственный сценарий и календарь на один месяц.
