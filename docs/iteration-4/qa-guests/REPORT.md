# B04–B05 · гости и пожелания

Статус: проверено на iPhone в браузере. Превью: http://127.0.0.1:5173/#booking-flow.

Композиция h5 и изменения D-022 сохранены: программа отеля на оплате, услуги на первом шаге. Выбор путешественника — компактная ссылка рядом с «Гость», дополнительные гости — исходное действие с пунктирной рамкой. Пожелания — строка под услугами и BottomSheet в стиле существующих подробностей; общий runtime и реакции не менялись.

В браузере проверены:
- Открытие списка путешественников, ввод второго гостя, отметка незавершённости, запрет продолжения без фамилии, редактирование и удаление.
- Прокрутка первого шага до пожеланий, выбор пункта, текст, счётчик, нейтральная рамка при фокусе, клавиатура и закрытие шторки.
- Полная перезагрузка: имя и пожелания восстановились, сумма осталась 26 980 ₽. Проверочные данные удалены из пользовательского черновика.
- При полной перезагрузке устранён устаревший путь в кеше Vite после переименования модуля: сервер перезапущен, загрузка проверена повторно.

Снимки: docs/iteration-4/qa-guests/guest-step.png, guest-step-lower.png, wishes.png, wishes-keyboard.png.

89 автоматических тестов проходят: совместимость старых черновиков, четыре гостя, уменьшение состава, частичные данные, ошибка оплаты, сохранение снимка, неизменность цены и профиля. Сборка, 28 защищённых файлов runtime и оба валидатора проходят. Предупреждение Vite о пакете более 500 kB остаётся; Android отдельно не проверялся.

Дополнительный сквозной сценарий в изолированном Chrome: четыре гостя, выбор сохранённого путешественника, пожелание, подтверждение с оплатой при заселении, перезагрузка и переход в поездку. Создана одна бронь на 50 160 ₽; три дополнительных гостя и пожелание сохранены, профиль не изменён, ошибок страницы нет. Снимок party-trip.png. Данные этого сценария не попадали в пользовательский браузер.
