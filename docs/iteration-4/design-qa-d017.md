# D-017 · компактная шапка выдачи

Дата: 22.10.2026. Результат: проверка пройдена в пределах D-017. Итерация 4 остаётся в работе.

Композиция c1 уточнена по прямому запросу пользователя: фильтры закреплены вместе с параметрами; сортировка перенесена в общий ряд чипов; строка количества удалена. Город и даты/гости оформлены кнопкой с карандашом и подписью «Изменить». Между параметрами и чипами 4 px. Сохраняются исходные шрифты, цвета, карточки и фото. Реакция на нажатие использует общие токены микровзаимодействий.

## Проверка в браузере

Codex In-app Browser, http://127.0.0.1:5173/#results, iPhone 393 × 852. Снимки полного холста в `docs/iteration-4/qa-d017/`:

- `results-top.png`, `results-scrolled.png`: параметры и чипы остаются на одной высоте, карточки прокручиваются под границей шапки.
- `sort.png`: сортировка из общего ряда открывает нижнюю шторку. «Сначала дешевле» даёт порядок 25 600 → 26 980 → 33 800 ₽; после проверки возвращены «Рекомендуемые».
- `edit-search.png`: кнопка «Изменить» открывает город, даты и гостей. Переход к отдельному календарю проверен, исходные даты сохранены.
- `before-map.png`, `after-map.png`: после открытия и закрытия карты положение списка сохраняется.

Фильтры k1 открываются из закреплённого ряда, закрытие без применения сохраняет параметры. Для даты и сортировки используется прежний BottomSheet. Исходники и защищённый mobile runtime не менялись.

## Сборка и границы

`npm --prefix app run build` проходит: TypeScript, Vite и контроль целостности 28 защищённых файлов. Предупреждение Vite о размере JS-пакета свыше 500 kB сохраняется. Бизнес-расчёты не менялись; новые автоматические тесты для изменения компоновки не добавлялись. Результаты предыдущего прохода: `docs/iteration-4/design-qa-d016.md`.
