## Проверка

- Карточки категорий, оснащение и условия открываются; элементы помещаются в область телефона. При проверке фильтров убраны лишние стандартные отступы заголовков: кнопка сброса теперь видна без прокрутки.
- Галерея делюкса содержит 7 загруженных исходных фото; категория «Ванная» оставляет одно соответствующее фото. Остальные категории номеров пока имеют по одному фото; счётчики показывают фактическое количество.
- Фильтр завтрака оставляет тарифы с питанием. Нажатие «Выбрать» переводит в оформление; на карточке и следующем шаге одинаковые 32 680 ₽ (13–15 ноября, программа отеля −5%). Контактный черновик сохраняется.
- Автоматически проверены вместимость, смена категории при изменении гостей, недоступность чужого/занятого номера, FR только для подтверждённого отельера, сохранение контактов и услуг, исключение двойной оплаты завтрака и оформление выбранного номера.
- 78 тестов проходят (`node --experimental-strip-types --test tests/*.test.mjs app/tests/*.test.mjs`), TypeScript/Vite build успешен, 28 защищённых файлов runtime неизменны. Валидаторы продукта и бренда проходят. Сохраняется предупреждение Vite о JS-пакете более 500 kB.
