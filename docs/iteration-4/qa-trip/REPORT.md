# Проверка u1b / подготовки к заезду · 22.10.2026

## Результат

- Композиция u1b: приветствие, кобальтовая карточка с фото 176 px, датами и оплатой, парные действия, чат/инструкция, список дополнений; стандартная нижняя навигация сохранена.
- При нескольких подтверждённых бронях — горизонтальный переключатель; чужие брони исключены, отменённые остаются отдельно.
- d4: время, адрес и вход, ресепшен, документы, парковка. Онлайн-регистрации и действующего ключа нет.
- d5 переиспользуется с данными выбранной брони, не меняя текущий поиск и независимый черновик.
- Ранний заезд ведёт в b3: доплата 2500 ₽ и сохранение обновляют заезд с 15:00 на 10:00; возврат из деталей — к услугам.
- Чат ch2 / список ch1: локальные исходящие сообщения, быстрые вопросы, клавиатура, сохранение после reload. История разделена по брони; новой поездке не показывается чужая переписка.

## Проверки

- 102 теста логики/worker: все проходят, включая владельца, выбор активной брони, свойства поездки, идемпотентность сообщений и независимость финансов/черновика.
- TypeScript/Vite build успешен; 28 защищённых файлов runtime неизменны. Остаётся прежнее предупреждение о JS-чанке более 500 kB.
- Валидаторы продукта и бренда успешны: 303 исходника + DOCX, 140 ассетов.
- scripts/verify-trip.mjs: главный экран → инструкция → маршрут → возврат; маршрут напрямую и назад; услуги → изменение → доплата → обновлённый заезд; чат → сообщение → reload; другая бронь с оплатой при заселении и отдельным чатом; список чатов. Ошибок страницы нет.
- scripts/verify-booking-record.mjs повторно прошёл: отказ/повтор доплаты, сокращение/возврат, сохранение, документ и отмена. Новые входы не сломали прежнюю ветку.
- Визуально проверены upcoming.png, guide.png, services.png, chat-keyboard.png, pay-at-hotel.png. Остальные снимки — route.png, chat.png, chats.png. Проверки использовали отдельный профиль браузера с вымышленными данными; пользовательские брони не менялись.

## Границы

Это проход предстоящей поездки, не завершение итераций 4–5. Обзор услуг пока использует общие строки UI kit/u1b; полный sv1–sv3, выбор времени d6, новые заказы и их оплата остаются далее. Переписка локальная, без реальных сообщений или ответов отеля. Документы d2, ключ после фактического заселения, счёт и выезд ещё не реализованы. Карта и транспорт сохраняют прежний демонстрационный характер. Рабочие настройки — P-017.
