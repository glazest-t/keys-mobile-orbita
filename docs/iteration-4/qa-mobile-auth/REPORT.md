# Мобильный вход и история поиска · D-037

23.10.2026. Последнее уточнение пользователя: приложение доступно только после авторизации. Предшествовавшее изменение гостевого режима отменено до завершения работы.

Общая проверка accessibleRoute применяется до отображения экрана. Без сессии внутренний маршрут заменяется телефоном, а целевой путь сохраняется для завершения входа. Онбординг доступен до входа; завершение ведёт к авторизации. При закрытии телефона доступен только онбординг. Служебные шторки поиска также не показываются без сессии. Кнопок «Продолжить без входа» нет.

«Недавние поиски» не отображаются при пустой истории. Блок появляется после выполненного поиска; история не очищается при каждом входе.

## Проверено

- Прямые ссылки без сессии: find, results, booking-flow, trips, profile, rewards, swipe, kit → телефон, без нижней навигации.
- Онбординг → телефон → код → имя → поиск. До завершения имени новый пользователь не получает сессию.
- Пустая история скрыта; после поиска виден один блок истории.
- Перезагрузка сохраняет действующую сессию.
- Выход возвращает на телефон. Возврат браузера и прямая ссылка на поиск после выхода не обходят вход.
- Встроенный браузер: закрытие входа возвращает к онбордингу, без доступа к поиску.
- Визуально проверен экран телефона: исходная композиция и обычная кнопка «Получить код», без гостевого действия (login-required.png).

Сквозная проверка scripts/verify-mobile-auth.mjs прошла в изолированном Chrome, ошибок страницы нет. 134 теста прошли, TypeScript/Vite build и контроль 28 защищённых файлов runtime успешны. Авторизация остаётся локальной демонстрацией, реальный SMS/backend не добавлялся.
