# Импорт отелей Москвы · 27.10.2026

Добавлены все 20 объектов из сохранённой выдачи Ozon Travel; всего в каталоге 33 отеля. Демонстрационные операции по новым объектам работают через прежние общие расчёты. Старые брони не заменяются.

## Данные

Названия, рейтинг, число отзывов, опубликованные удобства, фото отелей и цена за ночь взяты из источника. Ozon-мили исключены из удобств. Звёзды, которых нет в источнике, не показываются и сортируются после известных; это не категория «Без звёзд». Точные адреса и районы не придуманы: при отсутствии адреса указана известная станция метро. Для ibis есть адрес, фотографии стандартного номера 16 м² и цена с завтраком.

Рабочие тестовые значения остальных номеров: одна комната, двуспальная кровать, вместимость 2, 24 м², ванная/Wi-Fi, без питания. Наличие — 8 номеров до 31.12.2027; заезд/выезд 15:00/12:00, оплата онлайн/в отеле. Фиксированная цена снимка применяется на будущие даты; сезонное ценообразование не имитируется. Отмена по общему D-013 (исходный ibis был невозвратным). Эти настройки не являются фактическими обещаниями отелей. Детали — spec/imported-hotels.json.

Не скопированы тексты отзывов: показываются только исходные оценка и количество, просмотр текстов имеет пустое состояние. В 19 номерах без исходной фотографии — нейтральная заглушка. Карта остаётся схематической; мини-карта показывает шесть цен, развёрнутая — всю выдачу с позициями в пределах экрана.

## Проверки

Три новых интеграционных теста: все 20 объектов находятся, цена совпадает со снимком, бронь подтверждается, локальные фото существуют; неизвестные звёзды; оба тарифа/фото ibis. Все 15 целевых тестов импорта и фильтров прошли.

Полный проход: 266 тестов, 265 прошли; один прежний тест ожидал пустую Москву. Он уточнён: старый orbit-city по-прежнему недоступен, поиск возвращает только нужный город, неизвестный город пуст. Повторный проход всего commerce.test.mjs — 14/14. Сборка, TypeScript и защищённый runtime прошли.

В браузере: Москва, 20 новых карточек, фото/цены/мини-карта, детали ibis, реальные три фото номера, тарифы 33 800 и 39 000 рублей за две ночи, переход к данным бронирования с прежним итогом. Снимки находятся рядом.


## Дополнение: галереи и редакционные тексты

По следующему запросу пользователя у каждого из 20 отелей теперь 4–6 фотографий из его карточки Ozon: 96 в сумме. Фотографии верхних галерей считаны из DOM собственных страниц объектов, без подмены фото номеров и других отелей. Принадлежность/URL сохранены в gallery-evidence.json и gallery-manifest.json. Все 96 локальных файлов декодируются, у каждого отеля минимум четыре уникальных файла.

Добавлены 20 самостоятельно написанных кратких описаний и 59 вымышленных отзывов с вымышленными именами. Тексты отзывов источника не копировались. Эти примеры только для прототипа, их нельзя публиковать как отзывы реальных гостей. Данные явно маркированы в spec/hotel-editorial.json. Ранее отмеченное пустое состояние текстов отзывов заменено карточками по прямому запросу пользователя. Фото тестовых номеров, кроме ibis, по-прежнему остаются нейтральной заглушкой.

Проверка в браузере: пять фотографий «Окружной», переход в галерею и назад, два примера отзывов, фильтр «Номера», сортировка «Низкая оценка». Три теста импорта прошли; TypeScript, production build и проверка 28 защищённых файлов прошли.
