# Ozon Travel: Москва, 27–29 октября 2026

Пользователь предоставила ссылку на выдачу для пополнения каталога. Через браузер доступны 20 карточек с фотографиями, рейтингами, удобствами и ценами за две ночи для двух гостей. `import-candidates.json` — нормализованный набор, подключённый к демонстрационному каталогу после подтверждения пользователя. Пустые значения не заменяются вымышленными фактами.

`search-snapshot.txt` и `search-images.json` сохраняют источник полей. Для ibis Москва Киевская дополнительно сохранены открытая карточка и список изображений. На выбранные даты доступен стандартный двухместный номер 16 м²: без питания 33 800 ₽, с завтраком 39 000 ₽; в источнике оба тарифа невозвратные. Это не совпадает с общим демонстрационным правилом отмены приложения, поэтому автоматическое смешивание правил не выполнено.

Пользователь разрешила добавить отели. Недостающие настройки заполнены тестовыми значениями; полная маркировка полей — в spec/imported-hotels.json. Интеграция наличия/цен и обновление каталога в реальном времени не подключались. Статус: все 20 объектов доступны в интерфейсе. Цены фиксированы на ночь для проверки сценариев на будущих датах. Условия отмены — общие демонстрационные по D-013, а не реальные условия тарифов Ozon.

Дополнение: `gallery-evidence.json` содержит наблюдаемые заголовки/изображения 20 страниц, `gallery-manifest.json` связывает 96 подключённых фотографий с URL источника. Описания написаны самостоятельно; тексты отзывов генерируются как вымышленные демонстрационные примеры в `spec/hotel-editorial.json`.
