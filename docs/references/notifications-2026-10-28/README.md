У всех видимых строк стоит «История — не требуется». Поэтому добавленные в историю карточки являются только явно включаемыми примерами в инструментах демонстрации; автоматическое помещение этих событий в историю не реализовано. Вопрос пользователю о целевом поведении истории задан, ответа пока нет. Прочтение и существующие уведомления цены работают постоянно.

Пуши — внутренняя имитация по кнопкам настроек, без системной доставки и фонового расписания. Примеры не создают брони/ключи/начисления. 300 баллов — иллюстративный размер события, баланс берётся из текущего кошелька. Прямые решения пользователя об отсутствии онлайн-регистрации и доступе к ключу после заселения сохранены.
