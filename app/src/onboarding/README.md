# Онбординг текущей мобильной версии

Три шага используют RoomControlArt, BenefitsArt/BenefitsIntro и PersonalizationArt. Утверждённые иллюстрации находятся в app/public/brand/illustrations. Прежние HTML-иллюстрации и исследовательские варианты исключены из репозитория; локальные архивы сохранены.

Onboarding.tsx отвечает за шаги, прогресс и переходы. Первый шаг — управление номером, второй — баллы Ключей и программа отеля, третий — персональная подборка. Карточки второго шага собираются с разных сторон; третий имеет отдельную динамическую композицию.

LaunchSplash показывает ключ с орбитой перед сценарием входа. При биометрии это тот же холст, без повторного логотипа. Ошибка распознавания ведёт к PIN. SourceSplash содержит актуальную геометрию заставки и финала; motion.ts и source-motion.css — общие параметры движения.

После регистрации по приглашению отельера тур открывается с registered=true и завершается переходом в приложение. Повторное подтверждение статуса из профиля тур не запускает. Обычный новый пользователь видит тур до регистрации. Финальный переход — 1400 мс; reduced motion отключает пространственные переходы и ожидание. Таймеры отменяются при уходе; неактивные шаги исключены из взаимодействия и дерева доступности.

Актуальные примеры: каталог сцен onboarding-1, onboarding-2, onboarding-3 и launch. При изменении экранов проверять их в текущем приложении и каталоге.
