# Происхождение анимации

Источник: `проект в Клоде/project/github-onboarding/src/onboarding-variant-1.dc.html` из корня проекта, прямой выбор пользователя D-011.

o1.html–o3.html содержат оригинальные иллюстрации и transition-свойства. Шаблонные значения преобразованы в CSS-переменные; локальные фото используются из /brand/illustrations. motion.ts сохраняет исходные transform, задержки и порядок появления. SourceSplash.tsx переносит исходную геометрию заставки, орбитального акцента и финального знака; source-motion.css — исходные keyframes.

Onboarding.tsx связывает анимацию с React, доступными кнопками и настоящими маршрутами приложения. По D-037 «Начать» → вход → поиск; «У меня уже есть бронь» → вход → поездки. При действующей сессии повторный онбординг не требует нового входа для поиска. Финал занимает 1,4 с. Общая LaunchSplash перед сценарием входа: анимация 2,4 с и затухание 0,7 с; повторной заставки внутри шагов нет. Таймеры отменяются при выходе. При reduced motion переходы и задержки отключены. Неактивные экраны скрыты от взаимодействия и accessibility tree.

Шрифты, шапка, безопасные области и согласованные тексты остаются из действующего приложения. Полоски позволяют перейти на любой шаг, включая возврат. Горизонтальные свайпы не добавлялись: в выбранном исходнике управление кнопками и полосками.

## Исправление воспроизведения 21.10.2026

Иллюстрация вынесена в memo-компонент OnboardingArt со стабильной строкой html. Нельзя создавать новый dangerouslySetInnerHTML на каждом обновлении панели: React повторно назначает innerHTML, уничтожает начальные состояния CSS transition и прерывает движение при обновлении родительского таймера. Менять нужно только CSS-переменные у сохранённого дерева.

Холст иллюстрации — 343 × 356, как в источнике; font-size:16px, line-height:normal и content-box изолированы внутри source-art. Исходные inline box-sizing имеют приоритет. Первый экран уже расположен под заставкой, а после её закрытия начинают движение внутренние элементы. Порядок слоёв и непрозрачность фона панелей соответствуют источнику.

Сверка 31 анимированного элемента и снимки: ../../qa/motion-fix/. Результаты и ограничения записаны в ../../design-qa.md.

## Регистрация по приглашению отельера · 29.10.2026

После регистрации и завершения/пропуска подтверждения статуса существующий онбординг открывается с `registered=true`: финальная кнопка «Продолжить», без повторного входа и подписи «Войдём в ваш профиль». `State.hotelierTourTarget` сохраняет этап (`hotelier` — подтверждение, `trips` — онбординг перед приложением), включая перезагрузку. `finishHotelierEntry` переводит первичный вход к онбордингу; повторное подтверждение из профиля тур не запускает. `completeRegistrationTour` очищает только этот переход и отмечает просмотр; приглашение и ветка подтверждения сохраняются. Обычный онбординг до регистрации работает по прежним правилам.

Для биометрии LaunchSplash используется внутри DeviceUnlock вместо отдельного стартового экрана: исходная анимация → результат на том же холсте → вход. SourceSplash не перемонтируется при результате или повторе распознавания. Общая родительская заставка при этой ветке пропускается, чтобы не дублировать логотип. При ошибке доступен PIN, reduced motion показывает статичный знак.
