# Ключи Орбита

Мобильное приложение для поиска отелей, бронирования и управления проживанием. **Ключи от всех отелей.** Айдентика: Onest + Unbounded, кобальтовый #2F5BFF, визуальная основа «Ключи — Все экраны».

## Опубликованный проект

[Открыть сайт проекта](https://glazest-t.github.io/keys-mobile-orbita/) · [Прототип](https://glazest-t.github.io/keys-mobile-orbita/prototype/) · [Все экраны](https://glazest-t.github.io/keys-mobile-orbita/screens.html) · [Документация](https://glazest-t.github.io/keys-mobile-orbita/documentation.html).

Структура публикации и обновление: [DEPLOYMENT.md](docs/DEPLOYMENT.md). Публикация обновляется через GitHub Actions после push в `main`.

## Текущее состояние · 30 октября 2026

Мобильный демонстрационный прототип включает поиск и персональный подбор, бронирование, пять состояний поездки, услуги, ключ, чаты, уведомления, профиль, историю, программы отелей и Friendly Rate. Данные сохраняются локально; реальные интеграции не подключены. Десктоп — после финальной проверки мобильной версии пользователем.

Проведена сверка актуальных правил и документации, подготовлен **[единый пакет для разработки](docs/handoff/README.md)**. В нём последние решения отделены от старых вариантов и демонстрационных коммерческих настроек. Точный объём проверки и результаты — [отчёт актуальной публикации](docs/iteration-9/qa-current-publication/REPORT.md); приёмка пользователя ещё открыта.

Для локальной работы: [прототип](http://127.0.0.1:5173/#trips) · [Живой UI kit](http://127.0.0.1:5173/#kit) · [Брендбук](http://127.0.0.1:4173/docs/brand/index.html) · [Что проверить](docs/MOBILE-REVIEW.md).

СМС: **123456**. В инструментах демонстрации доступны шесть входов, пять стадий поездки и переключение ошибок. PIN для соответствующих демосценариев: **1234**.

Код — `app/`, общие расчёты — `prototype/domain/`, демоданные — `spec/`, токены/ассеты — `design/`. Команды запуска, проверки и границы runtime: [handoff](docs/handoff/README.md), [app/AGENTS.md](app/AGENTS.md). Локальный архив и защищённый runtime не изменять.
