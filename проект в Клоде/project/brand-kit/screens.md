# Ключи — экраны и сценарии v1.2

Эталон: `reference/prototype.dc.html` (кликабельный, открыть в браузере) и PNG в `screens/`. Все значения — из `tokens/`. Устройство макета 375×780 pt.

## Глобальная структура
- Нижнее меню (стекло Z3, r32, высота 64, отступы 14/18): **Поездки · Найти · Чаты · Выгоды**. Активная — кобальт + точка 5 px над иконкой. Скрыто на «Отель» и «Услуги».
- Шапка: знак 24 px (угол точки = этап поездки) + «ключи» Unbounded 20, справа колокольчик 40 и аватар 40.
- Вложенные экраны: кнопка «Назад» 44 (белая, рамка line) + заголовок по центру.
- Шторки: r30, затемнение 35%, одна главная кнопка 52. Тост: графит, точка статуса мятная, 2,6 с, над меню.
- Анимация появления экрана: opacity + translateY 14 px, 400 мс, arrive.

## Пустые и ошибочные состояния (сделать в продукте)
- Нет брони → этап «Мечтаю».
- Ключ недоступен (до 14:00 / нет регистрации) → кнопка вторичная «Ключ будет в 14:00», под ней «Пройти регистрацию».
- Нет сети → тост «Нет соединения. Ключ работает офлайн по Bluetooth».
- Неверный код → ячейки error + «Неверный код. Осталось 2 попытки».
