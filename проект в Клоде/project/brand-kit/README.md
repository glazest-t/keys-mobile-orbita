# Ключи — бренд-кит v1.2

Утверждённый бренд «Ключи» (концепция «Орбита»): исходники для дизайна и разработки.

## Состав
- `brand-spec.md` — спецификация бренда (логотип, цвет, шрифты, сетка, глубина, иконки, движение, голос, структура продукта).
- `prompt.md` — готовая инструкция для ИИ-агента (Claude Code и другие).
- `tokens/` — tokens.json, tokens.css, KeysTheme.swift, KeysTheme.kt.
- `logo/` — знак, горизонтальный и вертикальный логотип (кобальт, белый, графит), состояния живого знака, объёмный знак.
- `app-icon/` — иконки приложения iOS/Android, favicon.
- `icons/` — 102 интерфейсные иконки SVG + спрайт + icons.json.
- `motion/splash.html` — исходник заставки 2 с на чистом CSS (тайминги и кривые как в токенах).
- `screens.md` — описание всех экранов, состояний и переходов; `screens/` — 16 PNG-эталонов.
- `assets/` — фото для прототипа.
- `reference/ui-kit.dc.html` — полный UI Kit v2.0: все компоненты, состояния, анимации и взаимодействия.
- `reference/` — итоговое предложение агентства и превью бренд-кита (brand-kit-preview.dc.html — откройте в браузере).

## Как передать ИИ-агенту
1. Распакуйте архив в корень репозитория приложения, например в папку `/brand`.
2. Откройте агента в этом репозитории и напишите: «Прочитай brand/prompt.md и выполни задачу».
3. Проверяйте результат по экранам; при спорных местах отсылайте агента к brand-spec.md.

## Важно
- В SVG логотипов слово «ключи» набрано шрифтом Unbounded. Перед печатью и публикацией переведите текст в кривые (Figma: Outline stroke / Flatten; Illustrator: Create Outlines).
- Шрифты Unbounded и Onest распространяются по лицензии SIL Open Font License, их можно использовать в коммерческих проектах.
- Библиотека компонентов с живыми состояниями — reference/components.dc.html. Кликабельный прототип всего пути гостя — reference/prototype.dc.html.
