# Задача для ИИ-агента: применить бренд «Ключи» к приложению

Ты — senior-разработчик и дизайнер интерфейсов. В этом архиве — утверждённый бренд «Ключи». Применяй его ко всему приложению строго по правилам ниже.

## Что прочитать первым
1. `brand-spec.md` — все правила бренда.
2. `tokens/tokens.json` — значения. Для веба подключи `tokens/tokens.css`, для iOS — `KeysTheme.swift`, для Android — `KeysTheme.kt`.
3. `logo/`, `app-icon/`, `icons/` — готовые ассеты. Не перерисовывай их.
4. `reference/components.dc.html` — эталон компонентов и состояний. `reference/` — PDF итогового предложения и превью бренд-кита как визуальный эталон.

## Порядок работы
1. Подключи шрифты Unbounded (500) и Onest (400, 500). Убери другие шрифты.
2. Заведи токены как единственный источник цветов, радиусов, отступов, теней и анимаций. Никаких «магических» hex-значений в компонентах.
3. Собери компоненты строго по `reference/ui-kit.dc.html` (состояния, размеры, анимации). Базовые: Button (primary 52 / secondary 44 / text), IconChip 44, ListRow, Card, HeroCard (cobalt), GlassTabBar (4 вкладки), Sheet, Toast, Chip, Badge, ProgressRing (кольцо с точкой), OrbitLoader, OrbitMark (знак с параметром угла).
4. Замени все иконки на SVG из `icons/` (stroke 1.5, currentColor).
5. Собери все экраны по `screens.md`, сверяясь с PNG в `screens/` и прототипом `reference/prototype.dc.html`. Главная «Поездки» меняется по этапу брони (5 состояний).
6. Добавь заставку: точная геометрия и тайминги — motion/splash.html (перенеси на SwiftUI/Compose/Lottie 1:1) и OrbitLoader вместо системных спиннеров.
7. Перепиши тексты интерфейса по разделу 9 (голос и тон).
8. Проверь доступность: контраст ≥ 4,5:1, цели ≥ 44, reduce motion, reduce transparency. Тёмной темы нет.

## Жёсткие правила
- В шапке приложения — только знак 28 px, без надписи «ключи».
- На экране один кобальтовый блок — главное действие или текущая бронь.
- Лаванду и небо — только в свете, 3D и точке-спутнике, не в тексте.
- Unbounded — только логотип, заголовки экранов и крупные цифры. Всё остальное — Onest.
- Никаких начертаний 600+ (кроме логотипа — он уже в SVG).
- Точка знака двигается только со смыслом (этап поездки, загрузка, успех).
- Одновременно анимируется один элемент. Кривые и длительности — только из токенов.
- Тексты — на «вы», коротко, без восклицательных знаков.

## Критерии готовности
- Ни одного цвета, радиуса или шрифта вне токенов.
- Все экраны «Поездки» (5 этапов), ключ, услуги, выезд и лояльность — в новом стиле.
- Заставка ≤ 2 с, пропускается при reduce motion.
- Визуально совпадает с эталоном в `reference/`.
