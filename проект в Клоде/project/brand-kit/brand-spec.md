# Ключи — спецификация бренда v1.0

> Источник правды для дизайна и разработки. Значения — в `tokens/tokens.json` (и `tokens.css`, `KeysTheme.swift`, `KeysTheme.kt`). При расхождении приоритет у токенов.

## 1. Суть
- **Название:** «Ключи» (сеть и приложение). «Ключ» — функция цифрового ключа («Ключ готов»).
- **Идея:** «Вы — в центре». Кольцо — все отели «Ключей». Точка — гость.
- **Характер:** спокойный, точный, тёплый, технологичный без шума. Премиально, но не пафосно.
- **Стиль:** светлое пространство «Дневной свет»: перламутровый фон, кобальт как единственный акцент, матовое стекло, мягкий объём (Immersive 3D / Spatial).

## 2. Логотип
Файлы: `logo/`.
- Знак: кольцо, толщина = 0,1875·D; точка Ø = D/3; ореол точки = 0,06·D цвета фона (в SVG — вырез маской).
- Каноническое положение точки — 45° по часовой от 12 часов.
- Словесный знак «ключи» — Unbounded Medium, строчные, трекинг −5%. **Перед продакшеном перевести текст в кривые.**
- Охранное поле = D/3. Минимум: знак 16 px, горизонтальный логотип 72 px.
- Цвета: кобальт на светлом, белый на кобальте, графит для монохрома.
- Нельзя: менять пропорции, ставить точку внутрь кольца, градиенты/тени в плоском знаке, знак на пёстром фото без стеклянной подложки, прописные буквы.

### Живой знак (только в продукте)
| Состояние | Угол точки | Где |
|---|---|---|
| Мечтаю (поиск) | 270° | Найти, подбор |
| Еду (бронь до заезда) | 0° | Карта брони «Еду» |
| Я здесь (канон) | 45° | Логотип, заселение |
| Живу | 90° → 360° по ночам | Карта номера, кольцо прогресса |
| До встречи | 180° / замкнутое кольцо | Выезд, баллы |
| Не беспокоить | точка вне кольца | Статус номера |
Точка никогда не двигается без смысла.

### Точка — только акцент
Точка «Орбиты» — сильный, но утомляющий приём. Используем дозированно:
- **Можно:** логотип и знак в шапке, заставка, лоадер, одно кольцо прогресса в герой-блоке экрана, иллюстрации (онбординг, подборки, баллы, пустые состояния).
- **Нельзя:** индикатор активной вкладки, точки-статусы перед подписями, декоративные точки на аватаре, бейджи и кнопки, чипы.
- Не больше одной «брендовой» точки в видимой области экрана (не считая логотипа).
- Непрочитанное — единственный функциональный индикатор: точка 7 px только на колокольчике.

### Шапка приложения
Внутри приложения в шапке — только знак 28 px (кобальт), без надписи «ключи»: заголовок экрана — единственный крупный текст. Надпись используется на заставке, экранах входа (17 px, кобальт) и в маркетинге.

## 3. Иконка приложения
`app-icon/`: main (объёмный знак на светлом), cobalt, dark, tinted iOS, seasonal, Android adaptive foreground + monochrome, favicon. Экспорт PNG: iOS 1024, Android 432 (foreground на 108 dp, safe zone 66 dp).

## 5. Типографика
- **Unbounded 500** — логотип, заголовки экранов, крупные цифры (номер, цены, баллы).
- **Onest 400/500** — весь остальной текст и интерфейс.
| Стиль | Шрифт | Размер/строка | Трекинг |
|---|---|---|---|
| hero | Unbounded 500 | 56/60 | −4% |
| display | Unbounded 500 | 44/48 | −3% |
| h1 | Unbounded 500 | 26/32 | −2% |
| h2 | Onest 500 | 20/26 | 0 |
| headline | Onest 500 | 17/24 | 0 |
| body | Onest 400 | 15/23 | 0 |
| ui | Onest 500 | 14/20 | 0 |
| caption | Onest 400 | 12/17 | 0 |
| micro | Onest 500 | 11/14 | +1% |
Цифры — tabular-nums. Не больше 3 размеров на карточке. 600+ не используем.

## 6. Сетка, форма, глубина
- Шаг 4. Поля экрана 16. Между блоками 12. Между секциями 24.
- Радиусы: 8 · 12 · 14 (кнопки) · 16 · 22 (карточки) · 28 (герой) · 32 (нижнее меню).
- Кнопки: главная 52, вторичная 44. Строки 56–64. Цель нажатия ≥ 44.
- Слои глубины:
  - Z0 пространство — pearl + мягкий радиальный свет (gradient.space)
  - Z1 карточки — white, рамка line, elevation.z1
  - Z2 герой — cobalt, elevation.z2, внутренний свет
  - Z3 стекло — rgba(255,255,255,.72), blur 30, saturate 1.8, рамка 1px белая (нижнее меню, плашки поверх фото/3D)
  - Z4 шторки — white, затемнение фона 35%, elevation.z4
- Один 3D-объект на экран. Параллакс от гироскопа до 6 px.
- Reduce Transparency → стекло = белый 96%. Reduce Motion → без параллакса и вращений.

## 7. Иконки
`icons/` — 102 SVG, сетка 24, stroke 1,5, round caps/joins, `currentColor`. Есть `_sprite.svg` (id `k-<name>`) и `icons.json`.
- В интерфейсе: иконка в подложке 44×44, радиус 15, cobaltTint, иконка cobalt.
- Активная вкладка нижнего меню: цвет cobalt + подложка cobaltTint (pill). Без точки.
- Иконка `orbit` — фирменный значок баллов/лояльности.

## 8. Движение
| Кривая | Значение | Где |
|---|---|---|
| orbit | cubic-bezier(.65,0,.35,1) | движение по кольцу, морфинг |
| arrive | cubic-bezier(.2,.8,.2,1) | появление экранов, шторок |
| click | cubic-bezier(.34,1.56,.64,1) | точка «встаёт на место» |
| exit | cubic-bezier(.4,0,1,1) | уход элементов |
Длительности: 120 · 240 · 400 · 700 мс; заставка 2000 мс; оборот лоадера 900 мс linear; фоновые орбиты 20–40 с.
Ключевые сцены:
- **Заставка (2 с):** ключ по центру → стержень втягивается в точку прямо на кольце → точка проходит по орбите до 45° → знак уменьшается и уходит в шапку.
- **Лоадер:** точка бежит по кольцу (вместо системного спиннера).
- **Открыть дверь:** кнопка → лоадер-орбита → mint-вспышка + галочка + haptic success.
- **Баллы:** точка уходит на внешнюю орбиту, счётчик растёт.
- **Переходы:** общий элемент — точка/карта брони — переезжает между экранами.
Правило одного движения: одновременно анимируется один смысловой элемент.

## 9. Голос и тон
Спокойный консьерж: коротко, на «вы», по имени, без восклицаний, без капса, честно.
| Пишем | Не пишем |
|---|---|
| Открыть дверь | Нажмите, чтобы активировать цифровой ключ! |
| Подобрали для вас | Лучшие предложения только сегодня!!! |
| Что-то пошло не так. Попробуйте ещё раз | Ошибка 500 |
| Поездка, бронь | Тур, резервация |
| +2 240 баллов | Супербонус начислен! |
Слоганы: «Вы — в центре» (основной), «Весь отель вращается вокруг вас», «Ключи от любого отеля».

## 10. Структура продукта
Нижнее меню: Поездки · Найти · Чаты · Выгоды (профиль — аватар в шапке).
Главная «Поездки» меняется по этапу:
1. **Мечтаю** (нет брони) — приглашение подобрать отель, «Мой стиль».
2. **Еду** (бронь до заезда) — карта брони, кольцо обратного отсчёта, онлайн-регистрация, маршрут, ранний заезд, бронь и документы, чат с отелем, инструкция по заселению, изменить/отменить.
3. **Я здесь / Живу** — карта номера (номер Display 44–52, кольцо ночей, «Открыть дверь»), услуги, Wi‑Fi, завтрак, депозит, «Рядом с вами», есть проблема.
4. **Уезжаю** (день выезда) — выезд до 12:00, поздний выезд, счёт/депозит, «Всё с собой?».
5. **До встречи** — баллы за поездку, документы, отзыв, следующая поездка, пригласить друзей.
Лояльность «Орбита»: уровни Ближняя (с 1-й поездки, 3%), Дальняя (5 ночей/год, 5%), Высокая (20 ночей/год, 10%). 1 балл = 1 ₽. Число орбит на карте = уровень.

## 11. Хаптика и звук
select → light · confirm → medium · дверь/оплата → success · ошибка → error. Звук выключен по умолчанию, кроме открытия двери (щелчок + тон).
