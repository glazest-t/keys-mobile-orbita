# Ключи — брендбук «Орбита»

Версия 1.0 · октябрь 2026

## Идея
Кольцо — это все отели «Ключей». Точка — это гость. Положение точки на кольце показывает этап поездки: подбор (слева), бронь (сверху), проживание (справа), выезд (снизу). В логотипе точка стоит на 45° — момент перед заселением.

## Состав архива
- logo/ — знак (синий, белый, графит), горизонтальный и вертикальный логотипы, надпись. Надпись переведена в контуры, шрифт не нужен.
- app-icon/ — иконка iOS 1024 (без скругления: iOS маскирует сам), иконка со скруглением для маркетинга, foreground для Android adaptive icon (фон #3A66F0), PNG 1024/512/192/180/120.
- splash/ — анимация заставки: Lottie JSON (60 fps, 2.4 с, цикл), анимированный SVG, HTML/CSS, SwiftUI и Jetpack Compose.
- tokens/ — цвета, типографика, радиусы, отступы, анимации (JSON и CSS).
- brandbook.html — визуальный брендбук: откройте в браузере.

## Построение знака
Диаметр кольца = 1. Толщина кольца 0.1875. Точка: диаметр 1/3, центр лежит на средней линии кольца, угол 45° от вертикали по часовой стрелке. Вокруг точки отступ 0.06 цвета фона: в SVG он сделан маской, поэтому знак работает на любом фоне.
- Минимальный размер знака: 16 px.
- Охранное поле: не меньше диаметра точки (1/3) со всех сторон.
- Горизонтальный логотип: знак = 1.0 высоты, отступ до надписи 0.36, высота строчных = 0.58 знака.

## Интерфейс
Боковые поля 16, между карточками 12, внутренние отступы карточки 16, радиус карточки 20, крупных карточек 24, кнопок 14, высота кнопки 48. Иконки контурные, 22 px, линия 1.65 (src/arbana/icons.json). Активная вкладка нижнего меню — синяя на подложке #EEF2FE.

## Орбита в продукте
- Заставка: точка обходит кольцо за 2.4 с, easing cubic-bezier(.6,.1,.4,.9), бесконечный цикл; при prefers-reduced-motion точка стоит на 45°.
- Проживание: кольцо вокруг номера заполняется по дням, точка = сегодня.
- «Открыть дверь»: точка быстро бежит по кольцу (0.9 с, linear), после открытия кольцо замыкается и становится зелёным #16865A.
- Заказ «Готовится»: маленькое кольцо 14 px крутится.
- Лояльность: концентрические орбиты Silver / Gold, точка на текущем уровне.
- Онбординг: индикатор шага — знак, точка сдвигается на 90° с каждым экраном.

## Голос
Спокойный помощник: коротко, по делу, на «вы». «Номер готов. Дверь откроется с телефона». Без восклицаний и капслока.

## Заставка: интеграция
- iOS: Lottie (lottie-ios) — splash/keys-orbit-splash.lottie.json, фон в файле #3A66F0; или SwiftUI — SplashOrbit.swift.
- Android: Lottie (lottie-android) или Compose — SplashOrbit.kt; системный SplashScreen API: фон #3A66F0, иконка — app-icon/android-adaptive-foreground.svg.
- Web / React Native: splash.html (CSS) или Lottie.

Логотип и иконки — рабочие исходники концепта. Перед публикацией в сторах рекомендуется оптическая проверка знака дизайнером на малых размерах.
