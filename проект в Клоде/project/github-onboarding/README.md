# Ключи — прототип онбординга

Два варианта онбординга из трёх шагов, с заставкой «ключ → орбита» и анимациями в стиле бренда «Орбита».

| Файл | Что внутри |
|---|---|
| `index.html` | Стартовая страница со ссылками на оба варианта |
| `onboarding-variant-1.html` | Вариант 1 · всё в одном: номер в приложении → две выгоды → подбор по совпадению |
| `onboarding-variant-2.html` | Вариант 2 · управление: управление поездкой → лучшая цена и баллы → подбор по предпочтениям |
| `src/` | Исходники (Design Component) для правок |

Файлы `onboarding-variant-*.html` самодостаточные: шрифты, картинки и скрипты внутри, работают офлайн.

## Как выложить на GitHub Pages
1. Загрузите содержимое папки в корень репозитория (или в папку `docs/`).
2. Settings → Pages → Source: ветка `main`, папка `/` (или `/docs`).
3. Откройте `https://<user>.github.io/<repo>/`.

## Анимации
- Заставка 2,4 с: ключ втягивается в точку на кольце, точка проходит до 45°, появляется «ключи» и «Ключ от любого отеля».
- Переходы: экраны перетекают (opacity + сдвиг 36 px, 600–800 мс).
- Круговые композиции: элементы въезжают по орбите в порядке смысла (главное — последним, на 45°).
- Кривые: orbit `cubic-bezier(.65,0,.35,1)`, arrive `cubic-bezier(.2,.8,.2,1)`, click `cubic-bezier(.34,1.56,.64,1)`.
