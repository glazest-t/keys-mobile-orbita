# Ключи — запуск и вход

Сценарий: **заставка (ключ → орбита) → телефон → SMS-код → главная «Поездки»**.

## Состав
- `login-flow.html` — рабочий прототип (HTML/CSS/JS без зависимостей): заставка, ввод телефона с маской, клавиатура по тапу на поле, SMS-код, переход на главную. Подходит любой 4-значный код.
- `splash/splash.svg` — исходник заставки, слои названы по ролям.
- `splash/splash-animation.css` — keyframes заставки для переноса.
- `login-spec.json` — спецификация: токены, геометрия, ключевые кадры, тайминги, состояния экранов.
- `screens/` — кадры флоу: 01–04 заставка, 05 логотип в шапке, 06–07 телефон (без клавиатуры / с клавиатурой), 08–09 код, 10 главная.
- `assets/` — знак «Орбита» и фото.

## Заставка — 2,0 с
Минимализм: три состояния, бесшовные переходы, ничего не появляется и не исчезает само по себе.
1. **0–0,4 с · Ключ по центру.** Кольцо логотипа + стержень с одним зубцом.
2. **0,45–0,95 с · Ключ → «Орбита».** Стержень втягивается в кольцо и прямо на нём становится точкой; композиция мягко смещается, чтобы по центру оказалось кольцо.
3. **1,0–1,9 с · Точка по орбите.** Вокруг точки раскрывается зазор, она проходит по кольцу до 45°. Одновременно проявляются «ключи» и «Ключи от любого отеля».
4. **2,05 с** логотип поднимается в шапку экрана входа.

Easing `cubic-bezier(.65,0,.35,1)`. Ключевые кадры — в `splash-animation.css` и `login-spec.json`.

## Перенос в приложение
- **iOS (SwiftUI/Core Animation)** и **Android (Compose)**: повторить слои из `splash.svg` как фигуры, анимировать по таблице `splash.layers` из spec (доли от 2,2 с).
- **React Native**: Reanimated + react-native-svg, те же слои и тайминги.
- **Lottie**: импортировать `splash.svg` в After Effects, ключевые кадры из spec.
- Нативный launch screen = синий фон #3A66F0 (без знака), чтобы не было скачка до старта анимации.

## Промпт для другого ИИ-агента
> Реализуй экран запуска и вход для приложения «Ключи» на [стек]. Используй login-spec.json как источник правды по токенам, геометрии и таймингам; splash.svg и splash-animation.css — эталон анимации; login-flow.html — эталон поведения; screens/ — визуальная сверка.
