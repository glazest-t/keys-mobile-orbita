# Ключи — онбординг первого запуска

Четыре экрана объясняют суть приложения: персональный подбор отелей по лучшей цене → баллы лояльности → управление номером во время проживания → вся поездка от желания до выезда.

## Что в архиве
- screens/ — PNG каждого экрана (3x, 1014×2154, включая рамку телефона)
- html/ — каждый экран отдельным HTML с инлайн-стилями (открывается в браузере)
- onboarding-flow.html — интерактивный прототип: листание «Дальше» / «Пропустить» / свайп / ← →, переход 280 мс, живая анимация орбит на экране 2
- onboarding-all.html — все 4 экрана на одной странице
- onboarding-spec.json — машиночитаемая спецификация: тексты, токены, размеры, визуал, интеракции
- assets/ — фотографии и знак «Орбита»

## Как передать ИИ-агенту
Дайте агенту onboarding-spec.json и PNG из screens/ как эталон. Попросите сверстать экраны в нужном стеке (SwiftUI / Compose / React Native) по токенам из spec и брендбука. HTML-файлы — точный референс по отступам и размерам.

## Экраны
### 1. Отели под ваш стиль
Подберём то, что подходит именно вам, — по лучшей цене.

Кнопка: «Дальше»

Визуал: Фото отеля во всю карточку (assets/next-trip.jpg). Сверху чипы стиля: «Тишина», «У моря» (выбраны, синие) и «Поздний завтрак» (стекло). Внизу стеклянная карточка: «Береговой» 17/24 + «Сочи · 4,8 ★» 12/18 слева, «14 200 ₽» + «за ночь» справа; под разделителем плашки «Совпадение 94%» (синяя) и «Лучшая цена» (зелёная).

### 2. Баллы за каждую поездку
Копите и оплачивайте ими следующие поездки.

Кнопка: «Дальше»

Визуал: Синяя карточка. Концентрические орбиты: внешняя 270 px (Platinum, 2 px, 25% белого), средняя 190 px (Gold, 4 px, белая) с точкой гостя 26 px. В центре «+2 240» и «баллов · Gold». Внизу три миниатюры отелей с плашками начисленных баллов.

### 3. Номер в телефоне
Ключ, услуги и счёт — без звонков на ресепшен.

Кнопка: «Дальше»

Визуал: Фото номера (assets/maidens-premium-king.jpg) высотой 230. Поверх синяя стеклянная панель: «Ваш номер 412», «день 2 из 7», белая кнопка «Открыть дверь». Внизу три плитки 22 px иконок: «Все услуги» (иконка-сетка 2×2), «Завтрак в номер», «Wi‑Fi · подключить» (иконка вай-фая).

### 4. Вся поездка в одном месте
От выбора отеля до выезда.

Кнопка: «Начать» · вторичная: «У меня уже есть бронь»

Визуал: Белая карточка 316 px со списком из 4 этапов, соединённых вертикальной линией #E3EAFF. Строка: плашка 44 px (#EEF2FE, радиус 14) со знаком «Орбита» 26 px, где точка стоит на угле этапа; название 14/21 medium; подпись 12/18; номер 01–04 справа. Этапы: Выбор — Отели под ваш стиль (270°), Бронь — Цена и регистрация (0°), Проживание — Ключ, услуги и счёт (90°, строка выделена: фон #3A66F0, текст белый, плашка белая), Выезд — Документы и баллы (180°).

## Общие правила
- Шрифт Golos Text: заголовок 24/30 medium, текст 14/21 regular, подписи 12/18. Semibold — только в логотипе.
- Поля 16, визуал 356 (экран 4 — 316) с радиусом 24, кнопка 48 с радиусом 14.
- Индикатор: знак «Орбита» 22 px + «N из 4», точка сдвигается на 90° с каждым экраном.

## Анимация
- Экран 2: точка гостя — оборот по орбите Gold за 16 с (linear), малая точка — обратный оборот по Platinum за 28 с, блок баллов «дышит» (translateY 0→−3 px, 4 с ease-in-out). Keyframes lGold / lPlat / lPts — в <style> HTML-файлов.
- Переход между экранами: translateX, 280 мс, cubic-bezier(.2,.8,.2,1).
- prefers-reduced-motion: только смена прозрачности, фоновая анимация выключена.

## Интеракции
- «Дальше» — следующий экран, свайп влево/вправо тоже листает
- «Пропустить» — сразу на экран 4
- «Начать» — экран выбора стиля путешествий (квиз), затем главная «Поездки»
- «У меня уже есть бронь» — вход по номеру телефона и подтягивание брони
- Переход между экранами: горизонтальный сдвиг 280 мс, ease-out; точка в индикаторе поворачивается на 90° за 600 мс cubic-bezier(.2,.8,.2,1)
- prefers-reduced-motion: без сдвига, только смена прозрачности
